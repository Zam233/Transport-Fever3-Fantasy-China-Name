# 中国街道命名的地域分型差异调研报告

> 用途：为 Transport Fever 3「中国街道名」MOD 提供按地域呈现「地方风味」的街名生成素材与可编程配置。
> 调研人：中文方言与地名学研究员（会话 ID `2ce7fef0-070c-4981-bddb-f6f312a43b33`）
> 方法：以方言通名学 + 历史地理地名为框架，检索并核对了维基百科「胡同」「弄堂」「忠孝东路」等条目与多篇地名考据文献（来源见文末）。凡含义不确定处均标 **〔存疑〕**。

## 阅读与术语约定

- **通名**（generic）：街名的「尾巴」，标识道路/聚落类型与地域方言，如「胡同」「弄」「涌」「厝」「塬」。是 MOD 判断「这是哪里的路」的第一信号。
- **专名**（specific）：街名的「头」，提供语义与主题，如「史家」「徐家」「中山」「韶山」。
- **构词模板**：专名与通名的组合规则（如 `[姓氏]+家+[通名]` → 史家胡同、徐家汇、郭家沱）。
- 一条街名 = **专名（主题词）** + **通名（地域标记）**。同一个随机种子下，只要换掉「通名权重表」与「专名主题权重表」，就能得到完全不同的地域风味。
- 标 **〔存疑〕** 者：方言本字或语源学界有分歧，MOD 中仍可使用，但建议在注释里标注。

### 1.2 北京「胡同」语源专考（重点）

「胡同」语源学界有 **两类六说**，最可靠结论是：**源自古汉语「巷 / 衖」，与南方汉语「弄」同源，而非蒙古语**。但「蒙古语水井说」在民间与通俗读物中仍极流行，MOD 文档应如实呈现为「存疑」。

- **蒙古语水井说（流行但被质疑）**：蒙古语「水井」`khudag`（西里尔 `худаг`，音「湖都格 / 呼都格」），与「胡同」音近；因元大都聚落绕井而居，水井遂成街巷代称。此说见于明沈榜《宛署杂记》「胡同本元人语」，并因见于元杂剧（关汉卿《单刀会》「杀出一条血胡同」、李好古《张生煮海》「砖塔儿胡同」）而广为流传。
- **对水井说的质疑**：北京市地理学会王越指出——北京带「井」字的街巷并不多、水井主要分布在大街与菜园，且汉语吸收外来语多是因「前所未见的新事物」（葡萄、苜蓿、佛、塔），而「井」「巷」都是汉语早就有的词，无理由突然改用蒙古语词。
- **汉语音变说（学界主流）**：
  - **郑张尚芳「后衕音变说」**：「衕」《说文》「通街也」；古侯部字 o→u→ou 音变，宋代「后衕」即音如「胡洞」。
  - **黄现璠「衖巷音变说」**：`巷`（古音胡贡反，读若「弄」）→ 南方读「弄」，北方分化出「胡同」，故北京「胡同」与上海「弄」实为一词的两地方音。
  - **陆志韦 / 李方桂 / 丁邦新「复辅音假说」**：上古 `巷` 拟音 `*grongs`，复辅音 `gr-` 在北方裂为二字音（如「孔→窟窿」「角→旮旯」），在南方弱化为「弄」。
- **旁证**：朝鲜半岛「洞」（동，明洞、仁寺洞）本字即「衕」。

> **MOD 结论**：北京「胡同」与吴语「弄」是**同源异音**，可共用「巷/衖」这一底层通名，仅在表面读音/写法上分化为「胡同」vs「弄」。

### 2.2 上海路名的「以省名 / 城市名命名」与三级体系（重点）

- **省名 / 城市名命名（1862 年英租界工部局）**：南北向道路以**中国省名**命名（西藏路、云南路、四川路、河南路、浙江路、陕西路）；东西向道路以**城市名**命名（南京路、北京路、延安路、汉口路、九江路、福州路、广州路）。这一规则是上海老城路网「地名拼盘」的根源，也是 MOD 生成上海风味街名的高效手段。
- **三级体系**：`路`（主干道）→ `弄 / 里`（街坊内小巷）→ `号`（门牌）。标准地址形如「XX路 123 弄」；弄内再分「号」「室」。
- **里弄建筑命名**：成片里弄住宅取名「XX弄 / XX里 / XX坊 / XX村 / XX新村」（兴仁里、平安里、尚贤坊、建业里）。里弄的「里」= 街道围合街坊，「弄」= 街坊内道路，分**主弄**与**支弄**，支弄汇总到总弄连通街道。
- **词源**：里弄源自古「闾里」，唐代「里坊」；武汉汉口的同类建筑也称「里弄 / 里分 / 里份 / 里巷」。

### 3.2 粤语区「街/里/坊」、广府聚落、潮汕、海南、港澳差异（重点）

- **广府（珠三角）**：以**水乡地形通名**为绝对特征——涌、滘、围、基、沙、洲、塱、坑、沥、滘。聚落通名以「村」为主（冼村、猎德村、杨箕村），老城商业街多用「街/路/坊/里」（上下九、第十甫、状元坊、高第街）。
- **潮汕**：聚落通名偏向「乡 / 寨 / 社 / 里」，反映宗族围寨传统（龙湖寨、樟林、达濠）；海港地名多用「澳、浦、港」（汕头、潮阳）。
- **海南**：以「村 / 市 / 墟」为主，「市」常指**墟市/集市**而非城市——「那大市」即儋州那大镇旧称（今儋州市区）；府城、铺前等亦为墟市遗存。海南地名受闽南方言（海南话）影响，与雷州、潮汕同属闽语支。
- **港澳（葡英影响）**：
  - **香港**：街道名多为**英文音译/意译**，形成「道 / 街 / 里 / 径 / 台 / 坊」分层；大量以港督、官员、商人命名（皇后大道、弥敦道、干诺道、罗便臣道、轩尼诗道、德辅道、遮打道）。

### 5.2 湖南「冲」、湖北「垸/畈」、江西「垱/塅」（重点）

- **湖南「冲」**：`冲`（chōng）指**山间谷地 / 山冲**，是湖南丘陵区聚落典型通名——韶山冲（毛泽东故乡）、炭子冲（刘少奇故乡）。与水相关的「塘、湾、洲、矶」亦多（橘子洲、白沙井）。
- **湖北「垸 / 畈」**：`垸`（yuàn）指**江汉平原堤垸围垦**的围田区（洪湖、监利一带「人民大垸」等）；`畈`（fàn）指**山冲间平畈 / 田畈**（孝感、黄陂、大悟多「X畈」）。这是湖北「围垦 + 丘陵平畈」二元地貌的反映。
- **江西「垱 / 塅」**：`垱`（dàng）指**堤垱 / 拦水坝**（赣江流域）；`塅`（duàn）指**河谷平地 / 田塅**（赣南于都、兴国一带），为江西特色。
- **华中「铺 / 埠 / 矶 / 洲」**：沿江沿湖，`矶`（城陵矶）为江畔石矶，`洲`（鹦鹉洲、天兴洲、橘子洲）为江心沙洲，`铺`（十里铺）为驿铺，`埠`为商埠。

### 6.2 闽南「厝/埕/寮」、台湾政治性命名与「X路X段」（重点）

- **闽南「厝 / 埕 / 寮」**：`厝`（屋/聚落）是闽南聚落头号通名（厦门曾厝垵、何厝、黄厝、钟宅）；`埕`（晒谷场/庭院）与 `寮`（草寮/工寮）为闽南、台湾共同特征。
- **台湾政治性命名**：光复后以「三民主义 + 八德」命名的路网——`中山`（孙文）、`中正`（蒋中正）、`忠孝 / 仁爱 / 信义 / 和平`（四维八德）、`复兴 / 建国 / 光复`、`民生 / 民权 / 民族`（三民）、`自由 / 民主 / 博爱`。台北老城东西向以「忠孝、仁爱、信义、和平」命名，南北向以「中山、复兴、敦化、新生、光复」等命名。
- **「X路X段」分段体系**：长主干道按段落编号（忠孝东路一～七段、中山北路一～七段、和平东路一～三段），是台湾路名最鲜明的形式特征。
- **以大陆地名命名**：台湾城市格状路网大量以大陆省市名命名（重庆南路、南京东路、杭州南路、成都路、青岛东路、宁夏路、天津街）。

### 6.3 专名主题

- **闽南聚落**（厝、寮、埕、澳、屿、坑、埔、崎、头、尾、岑）
- **政治（三民/八德）**（中山、中正、忠孝、仁爱、信义、和平、复兴、光复、民生、民权、民族、自由、民主）
- **大陆地名转借**（重庆、南京、杭州、成都、青岛、宁夏、天津、长安）
- **地形/垦殖**（三张犁、六张犁、九份、八份、埔、坑、埤）

### 6.4 构词特点

1. `X厝 / X寮 / X埕`（闽南聚落）。
2. `方位 + 序数`（顶/下 + 寮/庄）。
3. 台湾：`政治词 + 路`、`政治词 + 路 + 段`（忠孝东路三段）。
4. 台湾：`大陆地名 + 路`（重庆南路）。

### 8.2 八角街（八廓街）式转经道命名（重点）

- 拉萨以**大昭寺**为中心形成三条转经道：`囊廓`（寺内回廊）、`八廓`（中圈，即八角街/八廓街）、`林廓`（外圈，绕老城）。「八廓街」是汉译（因「八」表方位四面八方的转经路径，非「八个角」），转经道命名是藏区城市街名的独特类型。
- 藏语地名多**整体音译**（那曲=黑河、拉萨、日喀则、昌都、林芝、阿里），通名「曲 / 错 / 塘 / 宗 / 卡 / 廓 / 林卡」嵌入专名后部。

## 9. 跨地域通用与混用规则（MOD 工程核心）

### 9.1 通用通名 vs 强地域标记

- **全国通用（低地域信息量，可任意地域使用）**：`路`、`街`、`巷`、`大道`、`大街`。这些通名几乎不透露地域，MOD 应将其设为「默认兜底」。
- **较强地域标记（用于区分南北/语区）**：`里`（多区有，但沪/粤/闽用法不同）、`坊`（沪/粤/闽）、`庄`（北/闽台）、`屯`（北/东北/西北）、`营/堡/寨`（北/西北/西南）、`湾/嘴/沟/墩/洲`（多区但权重不同）。

### 9.2 MOD 多地域覆盖方案：地域标签 + 通名权重表

核心思路：**一个随机种子 = 一个地域标签**，地域标签决定「通名权重表 + 专名主题权重表 + 构词模板表」的组合，从而同一随机种子在不同地图（不同地域标签）下生成不同风味的街名。

实现步骤：

1. **地域标签枚举**（建议粒度）：
   - `north`（华北/东北）、`wu`（江南/吴语）、`lingnan`（岭南/港澳）、`southwest`（西南）、`central`（华中）、`min`（闽台）、`northwest`（西北）、`tibet`（藏区）、`mongol`（内蒙古）。
   - 可再加 `central_hunan` / `central_hubei` / `central_jiangxi` 作为华中内部细分，避免「冲/垸/垱」混用。

2. **通名权重表**：每个地域一份「通名 → 权重」表，权重为相对整数（生成时归一化采样）。

3. **专名主题权重表**：每个地域一份「主题 → 权重」表，主题决定从哪个词库抽专名（姓氏、省名/城市名、地形、吉祥、行业、政治、颜色、音译人名等）。

4. **构词模板表**：每个地域一组「模板字符串 + 权重」，模板决定专名与通名的组合方式与附加成分（如「家」「序数」「段」「颜色」）。

5. **生成管线**：`seed → 地域标签 → 采通名(权重) → 采专名主题(权重) → 采专名词 → 套模板 → 输出街名`。

### 9.5 混用时的失真防控（避坑）

1. **强地域标记不跨区**：绝不在华北种子下生成「X涌/X滘/X厝/X塬」，也不在岭南种子下生成「X胡同/X沱/X冲」。
2. **华中省内细分**：`冲`→湖南、`垸/畈`→湖北、`垱/塅`→江西；若只有一个 `central` 标签，需给三者设低权重并在注释里说明，或拆三个子标签。
3. **「段」仅限台湾都市**：`X路X段` 只应在 `min` 标签的都市模式启用，且序数上限宜 1–7。
4. **「堡/铺」多音不混淆**：`堡` 在华北东北读 bǔ/pù（堡子/铺），在西北读 bǎo（城堡）；建模时按语义分桶。
5. **港澳音译人名独立词库**：`lingnan` 内港澳子模式专名走 `foreign_name`，广府走水乡地形，不要混。
6. **双语模式**：`mongol`/`tibet` 可加「音译 + 意译」双输出（呼和浩特 / 青城），用于双语路牌场景。
