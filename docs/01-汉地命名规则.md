# 汉地（传统"汉地十八省"）城镇命名规则报告

> 用途：为「生成虚构中国城市名」提供工程可用的规则底座。范围限定华北、华东、华中、华南、西南汉区（即清代的"汉地十八省"：直隶、山东、山西、河南、陕西、甘肃、四川、湖北、湖南、江西、安徽、江苏、浙江、福建、广东、广西、云南、贵州），不含东北、塞北、新疆、西藏等边疆与少数民族语地名体系。
>
> 原则：以语言事实为准；词源有争议处标注「存疑」；所有例证为真实地名，用于说明规则而非抄名单。

---

## 1. 构词模型

中文地名遵循 **「专名 + 通名」** 的二元结构，且基本为 **专名在前（前缀）、通名在后（后缀）**：

```
地名 = [修饰/定位成分] + 专名核心 + 通名
        方位·数字·颜色·大小    特征词        类型词
```

- **专名（specific）**：定位与区别——说明"哪个/什么样的"，来源为山水、方位、地形、物产、姓氏、历史、吉祥等（见第 3 节）。
- **通名（generic）**：分类——说明"是什么"，标识行政层级、聚落形态、自然地理类别（见第 2 节）。

例析：

| 地名 | 专名 | 通名 | 说明 |
|---|---|---|---|
| 洛阳 | 洛（洛水） | 阳 | 洛水之北 |
| 苏州 | 苏 | 州 | 古政区通名"州"已固化 |
| 石家庄 | 石家庄（石姓+家+庄） | — | 三字聚落名，"庄"为通名，整体又作更高层专名 |
| 驻马店 | 驻马 | 店 | 动宾式双字专名 + 店铺通名 |
| 洞庭湖 | 洞庭 | 湖 | 双字专名 + 自然通名 |

要点：
1. 通名可 **"专名化"后向上叠加更高层级通名**：`景德镇 → 景德镇市`、`石家庄 → 石家庄市`、`广州 → 广州市 → 广东省`。即低层通名（镇/庄/州）固化为专名的一部分。
2. 汉语地名是 **中心语后置（head-final）**，故"X 镇"是"以 X 命名的镇"，而非"镇之 X"。
3. 少数古地名保留 **通名前置** 的动词/方位结构：`镇海`（镇守海疆）、`宁波`（海波安宁，宋以"波宁"定名）、`市桥`（集市+桥）。属特例，生成时慎用。
4. 双字通名可连用表复合聚落：`城关镇`、`堡寨`、`屯堡`、`塘汛`、`洲岛`。

## 2. 通名体系（按层级与功能）

> 通名 = 语言中的"类标记"。生成虚构城市名时，通名决定地名的**体量感与地域感**，是最需精确的一环。

### 2.1 行政层级通名

| 通名 | 历史来源 | 适用场景 | 搭配限制 |
|---|---|---|---|
| **省** | 元代行中书省→行省 | 最高层级 | 虚构城市名一般不用 |
| **道/路** | 唐道、宋金元路 | 中高层政区 | 宋元"路"作专名残留（如"冀州路"），可入古名 |
| **府** | 唐代都督府/州府→明清普遍 | 明清统县政区 | 专名多双字 + 府：`广州府、开封府、严州府` |
| **州** | 上古"水中可居曰州"→汉十三州→唐宋大州/明清散州 | 极高频城名通名 | **专名几乎必为单字**：`苏州、杭州、扬州、徐州、广州、严州`；忌叠用 |
| **郡** | 秦汉郡县制 | 古名/雅名 | 已不通行，仅作历史地名素材 |
| **县** | 秦郡县制起，最稳定 | 县级 | 专名多为双字（`吴县、番禺`）或单字古县（`蓟、涪`） |
| **厅** | 清代新设政区 | 边疆/新垦区 | 汉地十八省较少用 |
| **镇** | 唐代军镇→宋商贸市镇→现代基层 | 市镇/乡级 | 现代与"市/县"不同层级，作通名时表聚落 |
| **乡/里/坊** | 先秦乡里→宋坊市 | 基层聚落/城市里坊 | 里坊为城市内部街区（`平康里、永和坊`） |

### 2.2 自然地理通名

| 类 | 通名 | 历史/语义 | 适用 |
|---|---|---|---|
| 山地 | 山、岭、峰、岗、丘、坡、岩、崖、岫、岑、崮 | 山体/岗丘 | 全国；崮为鲁中特有方山 |
| 水域 | 江、河、川、溪、涧、沟、渠、湖、泊、淀、池、潭、泉、井、湾、汊、港 | 水流/水体 | 全国 |
| 水边 | 洲、渚、滩、矶、浦、泾、浜、渎、浃、漾、荡、滘、涌、汊、埠、渡、津、塘、堰、陂 | 水中洲渚/河汊/水边聚落 | 洲渚滩矶全国；泾浜浦渎浃为江南；涌滘为岭南 |
| 平地/低地 | 坪、塬（原）、坝（坝子）、冲、坳、垄（垅）、塅、畈、垸、坎、槽、垭、垇、塝、塆（湾） | 各类平/洼/台/谷地 | 坪=华南；塬=黄土台地；坝/场/垭/槽=西南；冲/垄/塅=湘赣；畈/垸/塆=两湖 |

### 2.3 人文/军事/交通/商贸/聚落通名

| 类 | 通名 | 历史来源 | 适用场景 | 搭配限制 |
|---|---|---|---|---|
| 军事屯戍 | **卫、所、营、屯、堡、寨、关、隘、卡、哨、墩、台、戍、镇** | 明卫所制（卫=5600 人、千户所、百户所）；屯堡=军屯驻堡 | 卫/所→城名（`天津卫、威海卫、金山卫`）；屯/堡/寨/营→聚落 | 卫所名多保留为地名；堡多音（bǎo 堡垒/pù 铺/bǔ 有围墙村镇） |
| 交通驿传 | **驿、铺、站、塘、汛、渡、津、桥、梁、埠、亭、台** | 驿站递铺（十里一铺）；驿塘/塘汛 | 驿→城名（`龙泉驿`）；铺/店/站→交通聚落 | 铺常配数字里程：`十里铺、三十里铺` |
| 商贸市集 | **集、市、店、铺、坊、墟、圩、场、街、码头** | 定期集市（集/墟/圩/场）→定居聚落 | 集/店→华北中原；墟/圩→岭南闽赣；场/街→西南 | 集多配数字/姓氏：`辛集、大集` |
| 姓氏聚落 | **庄、村、屯、营、店、堡、寨、屋、楼、宅、家** | 宗族聚族而居 | `X家庄/X家村/X家屯/X家营` | 姓氏（或姓氏+家）+ 通名 |
| 水域商埠 | **埠、浦、港、津、码头、渡** | 水运码头 | `蚌埠、青浦、黄埔、天津、孟津` | 港在近代多指海港（`香港、连云港`） |
| 闽台专有 | **厝、寮、澳、屿、崙（仑）、坑、埔、埕、头、尾、社** | 闽语"厝/寮"=房屋/棚屋；澳=港湾；屿=岛 | 闽台/潮汕聚落 | 厝/寮常配姓氏或方位：`陈厝、田寮` |

> 关键约束：**通名的地域分布是强约束**——`泾/浜/浦/渎/浃/埭` 不出华北；`涌/滘/围/基/寮/埔` 不出岭南；`坝/场/垭/槽/坎` 是西南/陕南特征；`冲/垄/塅` 是湘赣特征；`厝/寮/澳/屿/崙` 是闽台特征。生成时"区域 × 通名"必须匹配，否则一眼假。

## 3. 专名来源分类（穷举 + 例证）

> 专名是地名的"血肉"，决定名字是否"像真"。以下按来源穷举，每类给真实例证与可复用部件。

### 3.1 山水形胜（以自然物命名）

**山系字**：山（庐山、巫山、井冈山）、岭（梅岭、庾岭、秦岭）、峰、岗（凤岗）、丘（灵丘）、岩、崖、岫、岑、崮（孟良崮）。
**水系字**：江（椒江、九江）、河（清河、漯河）、川（洛川、颍川）、溪（兰溪、竹溪、苕溪）、涧、沟、渠、湖（巢湖、洞庭湖、微山湖）、泊（梁山泊→梁山）、淀（白洋淀）、池（渑池、天池）、潭（龙潭、日月潭、桃花潭）、泉（温泉、趵突泉）、井（王府井、龙井）。
**水边字**：洲（瓜洲、橘子洲、白鹭洲）、渚（采石渚、牛渚）、滩（沙滩、河滩）、矶（燕子矶、采石矶）、浦（黄浦、青浦、彭浦）、泾（枫泾、漕泾）、溪、陂（芍陂）、淀。

规律：山水专名常与方位、颜色、大小、数量结合 → `东山、西河、长江、大溪、五湖、双溪`。

### 3.2 方位（定位词）

**核心方位**：东、西、南、北、中、上、下、内、外、前、后、左、右、里、表、首、尾。
**山水阴阳**（强约束）：**山南水北为阳，山北水南为阴**。

| 例 | 结构 | 逻辑 |
|---|---|---|
| 洛阳 | 洛水 + 阳 | 洛水之北 |
| 江阴 | 长江 + 阴 | 长江之南 |
| 华阴 | 华山 + 阴 | 华山之北 |
| 衡阳 | 衡山 + 阳 | 衡山之南 |
| 淮阴 | 淮水 + 阴 | 淮水之南 |
| 汉阳 | 汉水 + 阳 | 汉水之北 |
| 山阳 | 山 + 阳 | 山之南 |
| 汾阳、沔阳、邵阳、荥阳、溧阳 | 水 + 阳 | 各水之北 |

**上下/左右/内外/前后**：上蔡/下蔡、上杭（上游）、江左/江右（长江下游东西两岸）、江东/江西（唐"江南东道/西道"→专名）、内江、前门/后海、里/表。
**固定次序**：现代地名方位词几乎一律 **前置修饰**（东山、西湖、北桥、南关）；只有古雅用法保留 **后置**（江左、江右、江东、江西）。

### 3.4 物产与植被

以经济林木/作物/花草命名，是全国最普遍的专名来源之一：

- **林木**：柳（柳州、柳林、柳河）、松（松江、松山、松滋）、柏（柏乡、西柏坡）、槐（槐荫、洪洞大槐树）、樟（樟树、樟木头）、枫（枫桥、枫泾）、桐（桐乡、桐城、桐柏）、杨（杨柳）、榕（榕城、榕江）、椰（海南岭南）、桑（桑植、桑园）、枣（枣庄、枣强、枣阳）、梨（梨树）、茶（茶陵、茶山）、竹（竹溪、竹山）、梅（梅州、梅县、梅岭）、桂（桂林、桂平、桂东）。
- **花木**：莲/荷（莲花、莲塘、荷塘）、兰（兰溪、兰陵）、菊、桃（桃源、桃花江）、杏（杏花村、杏林）、荔（荔枝湾、荔城）、蒲（蒲江、蒲圻）、芦（芦洲、芦荡）、芷（芷江）、蓼、茅。
- 规律：`植被/物产 + 通名`（桐乡、茶陵、竹溪、枣庄、梅州）；或 `植被 + 地形`（柳林、桂林、梅岭、枫泾）。

### 3.5 历史政区与古国

以先秦古国、古州郡名为专名，多保留为城名/区域名：

- **古国**：吴、越、楚、秦、晋、齐、鲁、燕、韩、赵、魏、宋、陈、蔡、郑、卫、曹、莒、邾、滕、薛、邓、黄、蓼、六、巢、舒、皖、郧、鄢、邛、僰、滇、蜀、巴、夜郎（→夜郎）。
  - 例：`吴县、越城、秦川、晋阳、齐鲁、燕山、邾城、滕州、薛城、鄢陵、郾城、莒县、邳州、郯城`。
- **古九州/十三州**（作"州"的专名）：冀、兖、青、徐、扬、荆、豫、梁、雍、幽、并、益、凉、交。
  - 例：`兖州、青州、徐州、扬州、荆州、豫州、冀州、并州、幽州、凉州、益州、雍州、梁州`。
- **古郡县名残留**：会稽、琅琊、太原、汝南、颍川、南阳、涿、涪、蓟、邺、郢、姑蔑、余姚、句容、无锡（后三者越/吴语底层，词源**存疑**）。

### 3.6 军事屯戍

明卫所制与历代屯田留下大量军事通名化地名：

- **卫/所**（明卫所制，卫约 5600 人、千户所 1120 人、百户所 112 人）：`天津卫、威海卫、金山卫、观海卫`；"所"多残留在千户所/百户所地名。
- **营**（驻军）：`大营、小营、岳家营、刘家营、八旗营`。
- **屯**（军屯/民屯）：`王屯、大屯、新屯、留屯`（华北/东北/西南极多）。
- **堡**（军事城堡，晋陕甘读 bǔ）：`双堡、张堡、柴堡`。
- **寨**（军事堡垒/山民村寨）：`张家寨、袁寨、苗寨、侗寨`。
- **关/隘/卡/哨/墩/台**（关隘烽燧）：`山海关、居庸关、紫荆关、雁门关、函谷关、潼关、娘子关、剑门关`。

### 3.7 交通驿传

- **驿**：`龙泉驿、鸡鸣驿、郑家驿、马嵬驿`。
- **铺**（十里一铺递）：`十里铺、二十里铺、三十里铺、递铺、急递铺`。
- **站**：`车站`类现代命名。
- **塘/汛**（驿塘汛铺）：江南"塘"多兼水利+驿传（`横塘、七浦塘`）。
- **渡/津/桥/梁/埠**（渡口桥梁）：`风陵渡、瓜洲渡、桃叶渡、天津、孟津、江津、河津、板桥、枫桥、吕梁、蚌埠`。
- **关/隘**（险要通路，兼军事交通双重义）：见 3.6。

### 3.8 商贸市集

- **集**（北方定期集市）：`辛集、大集、双桥集、斑鸠集`。
- **市**（集市/市镇）：`沙市、牛市、羊市`。
- **店**（交通线店铺）：`驻马店、高碑店、长辛店、张店`。
- **铺**（店铺义，与驿铺合流）：`十里铺`（双解）。
- **坊**（作坊/街坊）：`米市坊、铁匠坊`。
- **墟/圩**（南方集市）：`新墟、古墟、圩镇`。
- **场**（西南赶场）：`牛场、羊场、马场、龙场`（王阳明"龙场悟道"）。
- **街**（西南集市街道）：`牛街、汉阳街、喜洲街`（云南"街"即集市）。

### 3.9 姓氏宗族聚落

> 中国最普遍的聚落命名方式之一，生成"像真的乡镇名"的主力。

- **姓氏 + 家 + 通名**：`张家庄、王家村、刘家屯、李家堡、赵家营、周家店、马家集`。
- **姓氏 + 通名**（省略"家"）：`王庄、李村、张营、马店、陈寨、孙集`。
- **复姓/双姓**：`欧阳村、诸葛村`（浙江兰溪诸葛八卦村）、`司马村`。
- **姓氏 + 屋/楼/宅**（客家/闽粤）：`张屋、李楼、曾宅`。
- 特例（已升格为城市名）：`石家庄`（石姓庄）、`张家口`（张姓驻守山口）、`张家界`、`周口`（周家口）、`张家港`。

### 3.10 吉祥教化与年号地名

**吉祥字**（可与"安/宁/平/定/昌/兴/顺/和/泰/康/靖/绥"搭配）：

| 吉祥字 | 例证 |

- **数量型**（山川/地物数量）：`三门峡`（三门峡口）、`三河`（三河交汇）、`四平`、`五台山`（五峰）、`六安`、`九江`、`十堰`（十道堰）、`五河`、`五峰`、`三台`。
- **里程型**：`五里铺、十里铺、三十里铺、五里亭、七里店`。
- **序号型**（屯垦/都图里甲序号）：`头屯、二屯、三屯`；`一都、二都、三都`（都图里甲制）；`头道、二道`。
- **首尾/上下型**：`头`（汕头=沙汕头、水头、沙头）、`尾`（沙尾、东尾）、`上/下`（上村、下村）。

### 3.12 方言与少数民族语转音

- **越/侗台语底层**（岭南）：`番禺`（越语，一说"盐村"，**存疑**）、`博罗`、`姑苏`（**存疑**）、`郁林`；侗台语地名字"那（田）、布（泉）、驮、打、岜、弄、洞/垌（平地/田）"多残留于岭南。
- **方言通名字**：吴语 `浜、泾、浦、渎、浃、埭、𡍲`（宁波"东乡十八隘、南乡十八埭，西乡十八𡍲"）；粤语 `涌(chōng)、滘(jiào)、塱/朗、埗、氹`；闽语 `厝、寮、澳、屿、崙(仑)、坑、埔、埕`；湘赣 `冲、垄、塅、塆(湾)`；川渝 `坝、场、垭、槽、坎、碚(北碚)`。
- 转音例：`辛集`（新集之音转，**存疑**）、`羊楼司`、`白坭`（泥）、`大朗`（大塱）、`深水埗`（步）。

### 3.13 避讳与改名

**避帝王讳改地名**（改字法为主，见陈垣《史讳举例》）：

- `启封县 → 开封县`（避汉景帝刘启）
- `建业 → 建康`（避晋愍帝司马邺）
- `恒山 → 常山`、`恒州 → 镇州`（避汉文帝刘恒）
- `玄武门 → 神武门`（避清圣祖玄烨）
- `广宁门 → 广安门`（避清宣宗旻宁）
- `真定府 → 正定府`（清雍正避世宗"胤禛"之"真"，同音避讳）
- `义兴 → 宜兴`（避宋太宗赵光义）
- 人名地名禁令：1949 年中共七届二中全会"不以人名作地名"、1986 年《地名管理条例》延续；但历史遗留人名地名多（`中山、志丹、左权、靖宇、尚志、黄骅、子洲、自忠`）。

**生僻字雅化/简化改名**（1955–1964 及异体字整理）：

- 生僻字→近音常用字：`新喻→新余、虔南→全南、盩厔→周至、郿县→眉县、醴泉→礼泉、葭县→佳县、沔县→勉县、洵阳→旬阳、栒邑→旬邑、雒南→洛南、汧阳→千阳、澂江→澄江、濬县→浚县`。
- 异体字整理：`封邱/商邱/沈邱→丘`；汉字简化（沈阳、郁南、阳谷等）。

**谐音雅化**：保留读音、换文雅字，如 `猪→珠、屎→史、尿→妙/料、坟→份、鸡→基/机、鬼→贵`（例：`珠海`，**存疑**）；`二沙头→二沙岛`（雅化例，见广州地名）。

### 3.14 明代卫所与清初移民地名

- **卫所地名**：明洪武十七年（1384）于军事要地设卫，卫所兼具行政组织，清雍正改卫所为府厅州县；`卫/所` 大量固化为地名。
- **移民故土记忆符号**（迁徙中转地成为"老家"代称，衍生大量以之命名/寻根的地名）：

| 移民潮 | 中转地 | 迁出→迁入 |
|---|---|---|
| 明初山西移民 | 山西洪洞大槐树 | 山西→河北/河南/山东/苏北/皖北 |
| 明初江西移民 | 鄱阳瓦屑坝 | 江西→湖广 |
| 清初湖广填四川 | 麻城孝感乡 | 湖广→四川 |
| 岭南移民 | 南雄珠玑巷 | 中原→岭南 |

- **新地命名**：移民垦殖聚落多以 `屯、庄、堡、营、场、窝棚` 命名（东北"XX 屯/窝棚"为山东移民，属关东体系，略）；四川"XX 场"多由湖广移民，两湖"XX 湾/畈/垸"与移民屯垦相关。
- 民谣实证（华北）：`"问我老家在何处，山西洪洞大槐树。祖先故居叫什么，大槐树下老鸹窝。"`

## 4. 组合规律与音韵限制

### 4.1 字数分布

| 字数 | 结构 | 占比倾向（经验估计，非权威统计） | 典型 |
|---|---|---|---|
| **2 字** | 单字专名 + 单字通名 | 县名绝对主体（约 85%+），城名高频 | 长安、洛阳、苏州、兰州、江阴 |
| **3 字** | 双字专名 + 单字通名；或 姓氏+家+通名；数字+通名 | 乡镇名主体，城名次之 | 驻马店、石家庄、张家口、景德镇、高碑店、十里铺 |
| **4 字** | 修饰 + 三字名；或双字专名 + 双字通名 | 少（汉区），多见于少数民族译音（非本报告范围） | 城关镇、东周家口、金沙洲 |

**何时用 3 字**：
1. 姓氏聚落：`X 家 + 通名`（张家庄、李家堡、周家口）；
2. 动宾/状中双字专名：`驻马店、望都、怀安`；
3. 数字 + 里程 + 通名：`十里铺、三十里铺`；
4. 双字自然专名 + 通名：`洞庭湖、鄱阳湖、日月潭、白鹭洲`；
5. 通名专名化后叠加：`景德镇`（景 + 德 + 镇）。

### 4.2 平仄 / 声调偏好

- **通名尾字偏好平声收尾**：`州、阳、阴、关、津、庄、村、桥、塘、城、门、安、宁、平、昌、兴、河、溪、湖、山` 绝大多数为平声（阴平/阳平），使整名以平声收、显得稳重响亮。
- **偏好平仄交错**：2 字名常见 `平平`（长安、江阴）、`仄平`（洛阳、溧阳、望都）；`仄仄` 与 `平平平` 连读偏钝，宜少。
- **避免拗口**：
  1. 同一声调三连（如三个去声连读生硬）；
  2. 声母相同（双声）或韵母相同/相近（叠韵）的字相邻（如"江乡""甘刚""沧江"读感差）；
  3. 与不吉/粗俗词同音近音（见 4.4）。
- 实操建议：**专名用字与通名形成"仄—平"或"平—平"搭配**；若通名为仄声字（如"集、店、寨、堡、渡"），专名取平声字起头（`辛集、张店、云寨、桃叶渡`）。

### 4.3 方位词与山水通名的固定次序

- 方位词现代一律 **前置**：`东山、西湖、北桥、南关、内江、前门`。
- 古雅用法可 **后置**（中心语前置）：`江左、江右、江东、江西、岭表`。
- **"X 阴 / X 阳"强约束**：前字必为**山名或水名**，且
  - **山南水北为阳** → `洛阳`（洛水北）、`衡阳`（衡山南）、`山阳`（山南）、`汾阳`（汾水北）；
  - **山北水南为阴** → `江阴`（长江南）、`华阴`（华山北）、`淮阴`（淮水南）。
  - 生成虚构"X 阳/X 阴"时，必须能自洽解释为"位于某山/水之南/北"，否则逻辑穿帮。

### 4.4 通名省略与叠用禁忌

- **同一通名不得自叠**：`吴县县、村村、州州、集集` 均错。
- **同义/同层级通名不得堆叠**：`县 + 镇`（县镇）、`州 + 府` 等行政重复；但通名"专名化"后向上叠加高层级通名是合法且常见的：`景德镇市、石家庄市、广州府、苏州市`。
- **双通名连用合法但语义须复合**：`城关镇`（城+关+镇）、`堡寨`、`屯堡`、`塘汛`、`洲岛`；避免无意义的两个同类通名硬拼。
- **市县同名问题**：历史上"废府存县/切块设市"产生大量市县同名，1983 年市管县体制后逐步撤并（截至 2026 年仍有 19 个县市同名）。生成虚构政区名时应避免"X 市"与"X 县"同名造成混乱。

```python
        # 规则2：吉祥字 + 吉祥通名（安/宁/平/昌/兴）
        pick(A_jixiang) + pick([安,宁,平,昌,兴,顺,和,泰,康,靖]),
        # 规则3：山水阴阳（X阳/X阴，需叙事自洽）
        pick(A_sanshui_水) + choice([阳, 阴]),
        # 规则4：古国 + 州
        pick(A_guzhou) + "州",
    ])

def gen_town(region):
    B = pick_group(region)
    return choice([
        # 规则5：姓氏 + 家 + 通名（3字聚落）
        pick(A_xingshi) + "家" + pick(B_juluo & B),
        # 规则6：姓氏 + 通名（2字聚落）
        pick(A_xingshi) + pick(B_juluo & B),
        # 规则7：数字 + 里程 + 通名
        pick([五,十,二十,三十]) + "里" + pick([铺,店,桥,亭]),
        # 规则8：方位 + 专名核心 + 通名
        pick(A_fangwei) + pick(A_sanshui | A_zhiwu | A_dixing) + pick(B & B_juluo),
        # 规则9：物产植被 + 地形通名
        pick(A_zhiwu) + pick([林,坪,坡,岗,塘,冲,坝,坪,洲,湾]),
        # 规则10：颜色 + 自然通名
        pick(A_se) + pick([沙,水,河,溪,岗,山,洲,滩,塘]),
    ])
```

## 7. 真实地名避让策略 + 自检清单

### 7.1 系统性避撞策略

1. **生僻组合**：用低频通名（`碚、埭、𡍲、滘、涌、塱、垸、塅、垭、坎、崙`）或低频专名字（`珩、泠、岫、潆、浥、畹、汀、沚、涘、岑、岈、峪、岬、瀼、漈、濂、淇、涪、邛、僰`）组合，天然远离高频真实地名。
2. **旧称变形**：取真实地名的古名/别名并换字——`金陵→秣陵`（"秣"+"陵"仍真实，需再换字：秣→"牧/沐"，陵→"泠/岭"），`白下、建康、姑苏、钱塘` 等旧称换字变形。
3. **方言转音**：用区域方言通名替代普通话通名（`泾/浜/渎/埭` 替"河/沟"，`涌/滘/围/基` 替"河/汊"，`厝/寮/澳` 替"村/屋"）。
4. **通名替换**：同一专名换不同地域通名——`临江 → 临浦/临泾/临川/临沚/临滘`，既避开"临江"又保留语义。
5. **专名替换**：同义/近义山水字互换（江/河/川/溪/泾/浦/渎、山/岭/岗/岑/崮）。
6. **合成虚构**：拼接真实存在但历史上不共现的前后缀（如"靖"+"碚"、"茶"+"滘"、"桐"+"塅"），生成"结构真实、组合虚构"的名字。
7. **发音避让**：除汉字不同外，还要避免与真实地名**同音**（如规避与"长安、南昌、武汉、南京、成都"同音近音的拼法）。
