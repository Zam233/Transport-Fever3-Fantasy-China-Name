# 「亚寒带中国」命名规则调研报告

> 面向 MOD 用途的虚构地名生成规范。语源考据基于 zh.wikipedia.org 各词条（经本地代理抓取原文，URL 见文末参考文献），存疑处均如实标注。
>
> **一句话结论**：外满洲（今俄罗斯远东）真实中文地名的核心风格，是 **「纯汉语自造的通名具象化地名」**（海参崴、庙街、双城子、海兰泡、三姓、江东六十四屯）与 **「满—通古斯语汉译/音译地名」**（宁古塔、依兰、阿勒楚喀、齐齐哈尔、吉林乌拉、兴凯、乌苏里、库页）两个系统的并置。**本 MOD 应复用的是前者（汉语自造），后者仅作为「边地风味点缀」按严格规则少量混入。**

---

## 1. 真实历史地名考据（核心）

> 分类标签：**〔汉自造〕**=汉语自造；**〔满汉译〕**=满语汉译（取义）；**〔满音译〕**=满语音译（取音）；**〔通古斯/蒙古汉写〕**=其他通古斯语或蒙古语族汉写；**〔音义兼通〕**=音译兼意译。

### 1.1 海参崴（Haishenwai，今符拉迪沃斯托克 / Владивосток）
- **语源**：清建政后满族赋满语名 **haišenwei（ᡥᠠᡳᡧᡝᠨᠸᡝᡳ）**，意为**「盛产海参的水洼」**；汉语写作「海参崴」。属**〔音义兼通〕**。
- **拆解**：`海参`（物产，且与满语 haišen「海参」同义）+ `崴`（东北方言通名，读 wǎi，义「水湾/水洼/山湾」）。满语 wei 与汉语「崴」音义两合，故为罕见的**音义双关借词**。
- **命名逻辑**：**物产 + 地形通名** 的三段式，是外满洲汉语地名的原型范式。俄名「符拉迪沃斯托克」义为「统治/征服东方」，与中文旧名语义无关。
- **争议点**：「崴」是否为纯汉语词存在两说——一说为东北汉语固有（wǎi 水湾），一说源自满语 wei。**存疑**，但作为生成器的通名无需纠结，两解都指向「水湾」义。

### 1.2 庙街（今尼古拉耶夫斯克 / Николаевск-на-Амуре）
- **语源**：**〔汉自造〕**。字面「有庙的街」。因黑龙江口旧有庙宇（永宁寺碑/观音庙等）得名。
- **命名逻辑**：**地标建筑 + 类通名（街）** 的两段式。极简、口语化、无生僻字，是「边地屯落」命名的典型。俄名以沙皇尼古拉一世命名，与中文旧名无关。

### 1.3 伯力（今哈巴罗夫斯克 / Хабаровск）
- **语源**：**〔通古斯汉写〕**（谐音转写）。又称「伯利」，源自**唐朝勃利州**；辽朝称「剖阿里」。**「伯利/颇黎/勃利/博和哩/剖阿里」均为「伯力」的汉语谐音**，来源于部落名**「博和哩」**（满语 **Bohori**）。
- **含义**：为部落/部族名，本身无汉字字面义（谐音字选择无明显义项）。**存疑**：Bohori 的原始语源与具体含义未见定论。
- **命名逻辑**：**部族名音译 → 单字/双字谐音转写**，后加行政区划字（勃利*州*）。俄名「哈巴罗夫斯克」纪念探险家哈巴罗夫。

### 1.4 双城子（今乌苏里斯克 / Уссурийск）
- **语源**：**〔汉自造〕**。建城时有**东西二城，相距四里**：东城清廷命名「傅尔丹」（满语 furdan hoton）、西城名「朱尔根」，两城合称**「双城子」**（满语对应 **juru hoton**，juru=双/成对）。
- **命名逻辑**：**数词 + 类通名（城） + 子缀**。`子` 是东北口语后缀（如「城子/沟子/泡子」），是强辨识特征。俄名「乌苏里斯克」由乌苏里江得名。

### 1.5 海兰泡（今布拉戈维申斯克 / Благовещенск）
- **语源**：原名**孟家屯**，后发展为城镇海兰泡（今日黑河市区旧名「黑河屯」亦曾称海兰泡）。**〔满汉译〕为主，另有一说**：
  - 主说：源自满语 **「海兰包」（Hailan Boo）**，意为**「榆树屯/树屯」**（hailan=榆树，boo=房/屯）。
  - 另说：源于蒙古语**「哈喇淖尔」（Харнуур）**，意为**「黑泡子」**（哈喇=黑，淖尔=湖沼）。
- **拆解**：`海兰`（满语 hailān 音译，义「榆树」）+ `泡`（汉语通名「泡子」，义「湖沼/水泡」）。**这是「满语音译专名 + 汉语通名」的混合构词**，与外满洲常见的「满语专名 + 汉通名」模式一致。
- **命名逻辑**：`泡` 是黑土地带特化通名，直接点出「水泡子」地貌。俄名「布拉戈维申斯克」义为「圣母领报之城」，与中文旧名无关。
- **争议点**：「榆树（满语）」与「黑水（蒙古语）」两说并存，**均如实列出，判「存疑」**。

### 1.6 尼布楚（今涅尔琴斯克 / Нерчинск）
- **语源**：**〔通古斯/蒙古汉写〕**。满语 **nibcu（Nibcu/Nibqu）**。清《朔方备乘》记其异写「尼布潮、尼布抽、尼布绰、泥朴处、泥扑处、你不楮」，**一地而译名各异**，为典型音译。原为蒙古诸部（布拉特/布里亚特、乌梁海、茂明安）游牧采捕之地。
- **含义**：nibcu 本身无汉字字面义，属纯音译。**存疑**（原始词义未见统一解释）。
- **命名逻辑**：**纯音译三音节**，是「音译化地名」的代表（尼布楚条约闻名）。俄名「涅尔琴斯克」由涅尔恰河得名。

### 1.7 外兴安岭（今斯塔诺夫山脉 / Становой хребет）
- **语源**：**〔满音译 + 汉语方位〕**。满语 **wehe noho amba hinggan**（直译「有石头的大兴安岭」）；达斡尔语 **Beedi Jidn dawa**。
- **拆解**：`外`（汉语方位词，与「内兴安岭」相对区分）+ `兴安岭`（hinggan，兴安/杭盖，蒙古—鲜卑语源山地通名，义近「大岭/黑山」一类，具体义存疑）+ 满语修饰成分。
- **命名逻辑**：**方位词 + 外来语山地通名**。俄名「斯塔诺夫」义为「主要的」（古俄语）；鄂温克人称其为「Dzhugdzhur（朱格朱尔）」，义为「地球的脊梁」。

### 1.8 库页岛（今萨哈林 / Сахалин）
- **语源**：**〔通古斯/阿伊努汉写〕**。唐代称**「窟说/屈设」**——「窟」（kur）可能音译自阿伊努语「人」（kur，阿伊努人自称），「说」（il）可能源自古阿伊努语「地」，故「窟说」= **「吾等人的陆地」**（kur-il）。元代称「骨嵬」，明代称「苦夷/苦兀」（皆指岛上阿伊努原住民），清代称「库叶/库野/库页」。
- **俄名溯源**：俄语「萨哈林」（Сахалин）音译自满语 **sahaliyan ula angga hada**（意为「黑龙江口之崖」，即「黑江嘴顶」）的首词 **sahaliyan**（义「黑」）。阿伊努语称「カムイ・カラ・プト・ヤ・モシリ」（神在河口创造的岛）；尼夫赫语称「尽头的大地/浮动的大地」。
- **命名逻辑**：**异族自称音译 → 汉字雅化改写**（骨嵬→苦夷→库页），是「音译地名不断改字趋雅」的典型。

### 1.9 江东六十四屯（俄称「满洲楔地」/「外结雅地区」）
- **语源**：**〔汉自造〕**。`江`（黑龙江）+ `东`（方位，指黑龙江左岸/北岸以东一侧）+ `六十四屯`（数目 + 屯）。又称「江左旗屯」「江东旗屯」。
- **命名逻辑**：**方位 + 数目 + 通名（屯）**。纯描述性，无任何外来语成分，是「屯垦聚落群」命名的极端范例（直接用村屯数量命名）。因1900年「海兰泡惨案」「江东六十四屯惨案」闻名。

### 1.10 瑷珲（又作爱辉，今黑河市爱辉区瑷珲镇）
- **语源**：**〔满音译/多解〕**。满语 **aihūn**。含义众说纷纭：
  1. 蒙语「可畏的武士」意译（「瑷」=可畏，「珲」=武士）；另有误传为达斡尔语「可畏」之说（载《龙沙纪略》）；
  2. 满语「母貂」（**aihū**）音译；
  3. 按文言解为「美玉」。
- **命名逻辑**：**音译为主，附会义项**。因《瑷珲条约》闻名。1956年因「生僻字地名」被简化改「爱辉」，2015年恢复「瑷珲」。
- **争议点**：三说并列，**均存疑**。

### 1.11 依兰（今依兰县）
- **语源**：**〔满音译〕**。满语 **ilan hala**，汉译为**「三姓」**，现取音译名「依兰」（ilan=三）。古称「五国城」（宋徽宗被囚死之地）。
- **命名逻辑**：**满语数词音译**。与「三姓」（汉译）构成**同一地名「音译/意译」双轨并存的绝佳例证**——满语 ilan 音译「依兰」、意译「三（姓）」。

### 1.12 珲春（今珲春市）
- **语源**：**〔满音译〕**。满语 **huncun（ᡥᡠᠨᠴᡠᠨ）**；达斡尔语 **Hongqn ail**。地处中朝俄三国交界。
- **含义**：具体义未统一，**存疑**（通说或与「边地/河汊」相关，但不确证）。
- **命名逻辑**：**纯音译双字**。

### 1.13 宁古塔
- **语源**：**〔满音译（带义）〕**。满语 **ningguta（ᠨᡳᠩᡤᡠᡨᠠ）**：ninggun（宁古）=「六」，-ta（塔）=「每…个」，合义**「每六个」**（一说源自当地六部落/六头领）。清初为宁古塔将军驻地、流放重地。
- **命名逻辑**：**满语数词 + 语法后缀 音译**。「塔」在此非汉语「塔」，是满语 -ta 的音译，易被望文生义，是「满语音译被汉字误读」的典型。
- **风格价值**：作为「极北苦寒」的文化符号（「发配宁古塔」），是本 MOD「北疆苦寒感」的核心意象词。

### 1.14 三姓（= 依兰）
- **语源**：**〔汉自造〕**（满语 ilan hala 的意译）。「三姓」= 三个姓氏/三个氏族，因赫哲/满族三部族（努业勒、葛依克勒、湖什哈哩）世居得名。
- **命名逻辑**：**数词 + 类名（姓）**。与「双城子」的「双+城」同构，是「数词 + 类通名」的汉语自造范式。

### 1.15 阿勒楚喀（今阿城，阿什河）
- **语源**：**〔满/女真音译〕**。满语 **alcuka（alquka）hoton**。雍正年间筑阿勒楚喀城，1908年设县简称「阿城」。阿城源于河名——阿勒楚喀河又称**阿什河**，是**女真语「金子」**之意（金朝国号或由此而来）。**〔存疑〕**（词条自标 citation needed）。
- **命名逻辑**：**河名（女真语）→ 城名 → 简称**。三音节音译是满语式地名的标志性音型（阿-勒-楚-喀，四字 A-AB-AB 结构）。

### 1.16 吉林乌拉（今吉林市）
- **语源**：**〔满音译（带义）〕**。满语 **girin ula**，义为**「沿江」**（girin=沿/带，ula=江）。今简称「吉林」，绰号「船厂」「北国江城」。
- **命名逻辑**：**满语「形容词 + 通名」结构音译**。`乌拉（ula）= 江` 是满语最核心的河流通名（牡丹江、乌苏里江、黑龙江皆同源）。

### 1.17 齐齐哈尔
- **语源**：**〔达斡尔语汉译〕**。语源标注为达斡尔语**「边疆」**之意；绰号「卜奎/卜魁/龙沙/鹤城」。
- **命名逻辑**：**达斡尔语四字音译**（齐齐-哈尔，AABB 式叠字音型），是北疆地名中「AABB 叠字音译」的代表（对比「呼和浩特」型）。
- **争议点**：另有「天然牧场」之通说，词条正文标注「边疆」；**两说并存，判存疑**。

### 1.18 漠河（今漠河市，中国最北城市）
- **语源**：**〔满音译〕**。满语 **mo bira**（蒙古名）；达斡尔语 **mee huarg**（早期记 Merihe huarg）；又作「墨河」。mo=树/木，bira=河。
- **命名逻辑**：**满语「名词 + bira（河）」结构音译**，被望文生义理解为「荒漠之河」。漠河金矿（老沟/胭脂沟）使其由驿站发展为边陲重镇，是「金矿 → 城镇」命名的历史路径范例。

### 1.19 雅克萨（今阿尔巴津 / Албазино）
- **语源**：**〔满/达斡尔音译〕**。满语 **yaksa（ᠶᠠᡴ᠋ᠰᠠ）**，达斡尔语 **Yaars hotn**；俄名「阿尔巴津」，清《清史稿》作「阿勒巴沁」。因雅克萨之战（1685—1686）与《尼布楚条约》闻名。本为索伦部达斡尔族所筑木城。
- **含义**：yaksa 具体义**存疑**（词条正文未给出统一义项，仅旁及「提咸河湾城」满语意为「涮塌了的江湾子」，与雅克萨本义无涉）。
- **命名逻辑**：**纯音译三字**。

### 1.20 乌苏里江（Река Уссури / Usuri Ula）
- **语源**：**〔满音译〕**。满语 **usuri ula**。含义**多解并列**：一说「水里的江」或「东方日出之江」，一说「天王」，一说「顺流而下」，一说「下游」，一说「黑如烟灰」。历代异名：唐「安居骨水」、金「阿里门河」、元「忽吕古江」、明「阿速江/速里河」。
- **命名逻辑**：**满语音译 + 汉语通名（江）**。`乌苏里` 是「满语式音译」的高频音型（乌-苏-里，u-su-ri）。

### 1.21 兴凯湖（Озеро Ханка）
- **语源**：**〔满音译〕**。满语 **hinkai/xingkai**，义为**「水从高处往低处流」**。唐代称「湄沱湖」，金代称「北琴海」（因湖形如月琴）。
- **命名逻辑**：**满语音译双字 + 汉语通名（湖）**。是「满语专名 + 汉语通名」混合构词的又一例。

### 1.22 牡丹江（Mudan Ula）
- **语源**：**〔满音译（带义）〕**。满语 **mudan ula**，义为**「弯曲的江」**（mudan=弯曲）。清代另称「虎尔哈河/瑚尔哈河」（满语 hūrha bira）。
- **命名逻辑**：**满语「形容词 + 通名」结构音译**，字面「牡丹」纯属音译选字，与花名无关——是「音译选字造成望文生义」的典型案例。

### 1.23 五常（今五常市）
- **语源**：**〔汉自造〕**。源自儒家**「三纲五常」**（仁、义、礼、智、信）。咸丰年间放荒垦殖，以五常之名设「举仁、由义、崇礼、尚智、诚信」五个甲社，遂称「五常」。
- **命名逻辑**：**汉文化抽象概念 → 垦殖区划名**。说明外满洲/东北汉语地名并不排斥中原儒家语汇，但落地形式是「屯垦组织」而非「州县城邑」。

## 2. 语源分层

### (a) 纯汉语自造 —— **本 MOD 要复用的风格**
| 地名 | 构词 | 逻辑 |
|---|---|---|
| 海参崴 | 物产 + 地形通名（崴） | 物产具象 |
| 庙街 | 地标 + 类通名（街） | 地标具象 |
| 双城子 | 数词 + 城 + 子 | 数量具象 |
| 三姓 | 数词 + 姓 | 数量具象 |
| 五常 | 抽象概念（儒家） | 概念化 |
| 江东六十四屯 | 方位 + 数目 + 屯 | 描述性 |

**特征**：不用外来语；通名高度具象（崴/泡/岗/砬/沟/甸/屯/仓/营/卡）；字数 2—4；口语化、可「望字明义」。

### (b) 满语 / 赫哲语 / 鄂温克语 / 达斡尔语汉译或汉写
- **满语汉译（取义）**：吉林乌拉（沿江）、牡丹江（弯曲的江）、兴凯（水从高处流下）、库页（黑江嘴崖，经俄语回转）。
- **满语音译（取音）**：宁古塔（每六个）、依兰（三）、珲春（义存疑）、阿勒楚喀（金子，存疑）、漠河（mo bira 树河）、瑷珲（多解）、尼布楚、雅克萨、乌苏里。
- **达斡尔语**：齐齐哈尔（边疆/牧场）、漠河（mee huarg 异写）、雅克萨（Yaars hotn）。
- **通古斯/阿伊努**：库页（窟说/骨嵬，阿伊努 kur-il）、外兴安岭（hinggan，蒙古—鲜卑语源）。

### (c) 音译化地名
纯取音、字面无义：尼布楚、雅克萨、珲春、乌苏里、阿勒楚喀、齐齐哈尔。**辨识点**：多为 3—4 字、出现「喀/楚/库/齐/布/呼/穆/乌/苏」等边地音译高频字。

> **结论**：(a) 是主风格（可自造、可编程、辨识度高）；(b)(c) 作为「风味点缀」按**严格音型规则**少量混入，避免喧宾夺主。

## 5. 风格辨识特征（如何一眼看出「亚寒带/北疆」而非中原）

1. **特化通名**：`崴/泡/岗/砬子/甸子/卡伦/窝棚/地窨子` 出现即锁定北疆/关东。
2. **渔猎物产专名**：`鲟/鳇/鲑/大马哈/貂/狍/獾/海东青/参` 直指寒地渔猎经济。
3. **满语式三音节音译**：`-乌苏里 / -图们 / -吉林 / -宁古塔 / -阿勒楚喀 / -齐齐哈尔 / -尼布楚` 的「乌/苏/图/吉/宁/喀/楚/齐/库/呼」音型。
4. **寒冷水文意象**：`冰/雪/霜/凌/冻/寒` 大量入名。
5. **数词 + 通名**的朴素构词：`双城子 / 三姓 / 六十四屯`（不用中原式的「×州/×县」）。
6. **方位 + 江/岭**：`江东 / 江北 / 外兴安岭`（以「江（黑龙江）」为基准坐标）。

**反例（中原式，应规避）**：州、县、府、郡、阳、阴（洛阳/江阴式）、陵、关内名物（梧桐/凤凰/杨柳/牡丹园）、纯行政现代名（新区/开发区/高新区）。

## 6. 音韵与结构约束

### 6.1 字数分布
- **2 字**：伯力、庙街、依兰、珲春、瑷珲、漠河、五常（多为音译或极简自造）。
- **3 字**：海参崴、双城子、海兰泡、宁古塔、尼布楚、雅克萨、三姓（+通名省略）。
- **4 字**：阿勒楚喀、齐齐哈尔、吉林乌拉、外兴安岭。
- **≥5 字**：江东六十四屯（描述性，罕见，慎用）。

### 6.2 两大范式
- **「海参崴」式（物产/特征 + 地形通名，三段式）**：`[物产|特征|数词] + [地形通名]`。例：鲟鱼泡、貂皮沟、桦林岗、参砬子、鹿岔。
- **「庙街」式（地标/类名，两段式）**：`[地标|数词|方位|概念] + [类通名](+子/儿)`。例：庙街、双城子、三姓、五常、江东屯。

### 6.3 满语式音译常见音型（可模拟）
- **双音节 + 汉语通名**：`乌苏里 + 江`、`兴凯 + 湖`、`海兰 + 泡`、`漠 + 河`。
- **三音节独立**：`宁古塔、尼布楚、雅克萨、珲春（双字）`。
- **AABB 叠字**：`齐齐哈尔`。
- **-乌拉 / -图们 / -吉林 / -宁古 / -阿勒楚喀** 结尾音型；`乌/苏/图/吉/宁/喀/楚/库/齐/呼/穆/雅/勒` 为高频音译字。
- **满语通名词根（可作后缀）**：`ula（江）、hoton（城）、bira（河）、hada（崖）、alin（山）、karun（哨/卡伦）、mudan（弯）、boo（屯/房）`。

### 6.4 会「显得像中原」的组合（应避免）
- `×州 / ×县 / ×府 / ×郡 / ×阳 / ×阴 / ×陵`；
- 南方/关内物产（茶/竹/桂/樟/梅/樱/荷/莲）；
- 园林化、书卷气词汇（栖霞/听雨/流觞/兰亭/锦绣）；
- 现代行政区划词（新区/开发区/高新区/产业园）。

## 7. 生成算法（可编程）

### 7.1 数据表

**专名部件（P）** —— 分五簇：

```
屯垦   = [屯, 窝棚, 地窨, 连, 队, 仓, 垦]
数词   = [单, 双, 三, 五, 六, 七, 八, 九, 十, 百]

```

**通名（T）** —— 亚寒带特化：
```
地形   = [崴, 崴子, 泡, 泡子, 岗, 冈, 砬子, 沟, 岔, 甸, 甸子, 岭]
水域   = [江, 河, 溪, 汊, 岛, 渚, 湾]

戍边   = [卡伦, 哨, 台, 墩, 堡, 城, 卫, 所]

```

### 7.2 组合规则
- **规则 R1（海参崴式，主）**：`修饰? + 物产|水文|矿业 + 地形|水域通名`。例：`白`+`桦`+`岗`=白桦岗；`鲟`+`泡`=鲟鱼泡；`砂金`+`沟`=砂金沟。
- **规则 R2（庙街/双城子式）**：`数词|方位|地标 + 类通名(+子)`。例：`双`+`城`+`子`=双城子；`三`+`姓`=三姓；`江左`+`屯`=江左屯。
- **规则 R3（戍边式）**：`方位|修饰 + 戍边通名`。例：`北`+`卡伦`=北卡伦；`老`+`营`=老营；`青`+`哨`=青哨。
- **规则 R4（满语音译点缀，≤10% 混入）**：用满语词根组合再音译。仅使用**已证词根**（见 6.3），例：
  - `ilan + bira` → 依兰必喇（义「三河」）；
  - `ninggun + hoton` → 宁古霍屯（义「六城」，呼应宁古塔音型）；
  - `amba + hada` → 安巴哈达（义「大崖」）。
  > **警示**：R4 生成的是「满语式音型模拟」，其「满语义」仅当词根确证时才成立；写进游戏设定时应仅作「音译地名」处理，**不附会虚构的满语义**，以免编造。

### 7.3 禁忌过滤（生成后逐条过滤）
1. 精确命中真实地名表（见 §8）→ 丢弃；
2. 含中原通名（州/县/府/郡/阳/阴/陵）→ 丢弃；
3. 含现代通名（新区/开发区/高新区/新城）→ 丢弃；
4. 含关内/南方物产（茶/竹/桂/樟/梅/樱/荷/莲）→ 丢弃；
5. 与已生成列表重复或编辑距离 < 1（如「鲟鱼泡」vs「鲟鱼泡子」视为近撞）→ 丢弃；
6. 音近真实地名（拼音/谐音，如「海参湾」撞「海参崴」联想）→ 丢弃或降级。

### 7.4 产量估计
- 部件库规模：P ≈ 60、T ≈ 40、修饰/数词/方位 ≈ 30。
- R1 组合空间 ≈ 修饰(30) × 物产水文矿业(45) × 地形水域(25) ≈ **3.3 万**；叠加 R2/R3 再增数万。经禁忌过滤后仍可稳定产出**数百至数千个不重复、不撞真实地名的名字**，满足 MOD 需求。

## 8. 真实地名避让策略与自检清单

### 8.1 避让策略
1. **黑名单库**：内置全部外满洲/东北真实地名（海参崴、庙街、伯力、双城子、海兰泡、尼布楚、雅克萨、瑷珲、珲春、依兰、宁古塔、三姓、阿勒楚喀、吉林、齐齐哈尔、漠河、漠河…），及全国县级以上行政区划名、知名聚落名。
2. **匹配方式**：① 全串精确匹配；② 去「子/儿/崴子/泡子」等缀后的词干匹配；③ 拼音（含声调归一）匹配；④ 编辑距离 ≤ 2 的模糊匹配。
3. **联想避让**：避免生成与真实名「同首段专名」的变体（如真实「海参崴」→ 禁「海参×」全系），防止玩家误认。
4. **去重**：全局唯一约束 + 编辑距离 ≥ 2。

### 8.2 自检清单（每个生成名逐项打勾）
- [ ] 字数 2—4（描述性长名除外）；
- [ ] 通名 ∈ 亚寒带特化集（崴/泡/岗/砬/甸/沟/卡伦/窝棚/地窨/屯/仓/营/林场/金沟…）；
- [ ] 无中原通名（州/县/府/郡/阳/阴/陵）；
- [ ] 无现代通名（新区/开发区）；
- [ ] 语源自洽（纯汉语自造 或 满语音译，二者不混杂词）；
- [ ] 未命中真实地名（精确/词干/拼音/编辑距离）；
- [ ] 未命中已有虚构地名；
- [ ] 朗读通顺（「海参崴」式可读作 X + 通名，不拗口）。
