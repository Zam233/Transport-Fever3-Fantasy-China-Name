# 「海洋中国」假想命名规则报告

> 用途：为虚构世界观生成**「南洋华人/华人势力主导的东南亚港口与聚落」的中文城市名**。
> 前提假设：中国文明/华人势力（闽南、潮州、广府、客家、海南、福州六帮）深度拓展并主导越南、占城、柬埔寨、暹罗、马来半岛、爪哇、苏门答腊、婆罗洲、菲律宾、缅甸沿海。
> 方法：先做真实历史地名考据（合法性与可信度来源），再提炼可编程的构词规则。
> 全文以**可复用构词规律**为主，不以罗列真实城市清单冒充规则。

## 1. 历史真实基底（真实考据，规则可信度来源）

### 1.1 越南汉越地名体系：汉越音是「天然中文名生成器」

越南语中**汉越词（Từ Hán Việt）约占词汇量 60%**，政治、法律领域更高达 70–80%。汉越词保留了古汉语（中古音）的读音，即**汉越音**——这正是「汉越地名」能被读成、写成、甚至逆向生成地道中文名的原因（见 [参考文献 1]）。

**通名对译表（行政/聚落通名，可直接复用）：**

| 越南语（国语字） | 汉越汉字 | 含义 | 用法 |
|---|---|---|---|
| thành phố | 城庯 | 城市（字面「城＋街市」） | 河仙市 = Thành phố Hà Tiên / 城庯河僊 |
| thị xã | 市社 | 市镇（县级市） | 会安市社 → 会安市 |
| huyện | 县 | 县 | 坚良县 |
| xã | 社 | 乡/社 | 顺安社、仙海社 |
| tỉnh | 省 | 省 | 广南省 |
| phường | 坊 | 坊（城区） | 平山坊、东湖坊、明安坊 |
| thị trấn | 市镇 | 镇 | — |
| phố | 庯 | 街市/店铺 | 锦铺坊（Cẩm Phô） |

**可放心的汉越地名构造**（音 + 义对译，非音译）：
- 河内 Hà Nội（河＋内）、升龙 Thăng Long（升＋龙）、顺化 Thuận Hóa（顺＋化）、会安 Hội An（会＋安）、河仙 Hà Tiên（河＋僊，本字「僊」即「仙」）、嘉定 Gia Định（嘉＋定）、边和 Biên Hòa（边＋和）、海防 Hải Phòng（海＋防）、谅山 Lạng Sơn、太原 Thái Nguyên、老街 Lào Cai。

**纯音译（借音不借义，不宜当「汉越规则」滥用）**：
- 芹苴 Cần Thơ、美湫 Mỹ Tho、芽庄 Nha Trang（占语源）、金瓯 Cà Mau（高棉语源，汉写「金瓯」恰好是汉语成词「金瓯无缺」的附会）、西贡/柴棍 Sài Gòn（高棉语「柴棍」，华人雅化为「西贡」）。

**结论**：越南一侧的「海洋中国」城市名应**优先走汉越音 + 吉祥字**路线（新/安/隆/平/山/河/海/金/玉/福/永/广/顺/明/清/富/泰/兴/利/和），几乎每个都能自然产出 2 字雅名；「城庯/市社/坊/社/县/省」这套通名体系可整套移植为「海洋中国」的行政通名。

### 1.2 华侨聚居地名：音译 / 意译 / 自造 三分法（核心分类）

这是整套规则最重要的分类框架。真实东南亚华人地名几乎都落在这三格之一：

**① 音译（借音不借义，拗口、多音节）**
- 曼谷 Bangkok：泰语 บางกอก（Bang Kok），「曼」= 河边聚落（Bang），「谷」= 橄榄树；**潮州人按潮阳话译作「曼谷」**（[6]）。
- 巴邻旁 Palembang（巨港的音译名）、满剌加/麻六甲 Malacca、苏腊巴亚 Surabaya（泗水的音译名）、坤甸 Pontianak、庇能 Penang（闽南语音译 Pulau Pinang）、丁加奴 Terengganu、吉兰丹 Kelantan、漾贡 Yangon。

**② 意译（借义，直译当地语义）**
- 槟榔屿 Pulau Pinang：因岛上多槟榔树，直译为「槟榔＋屿」（[5]）。
- 旧港 Palembang：明 1407 年设「旧港宣慰司」，因三佛齐故都而名「旧港」（[7]）。
- 唐人山 / 三保山 Bukit Cina：马六甲华人墓山，直译「唐人山」，又附会郑和称「三保山」（[8]）。

**③ 华人自造 / 雅化（音译 → 谐音 → 附会出有意义汉名）**——这是「海洋中国」最值钱、最该复用的机制：
- **泗水** Surabaya：爪哇语 Sura（鲨鱼）＋Baya（鳄鱼）＝「鲨鱼鳄鱼之地」，音译「苏腊巴亚」拗口 → 华人先谐音「泗里木」→ 再雅化为「泗水」，并附会曲阜泗水、闽南「泗洲佛祖」（男相观音）信仰（[4]）。
- **巨港** Palembang：音译「巴邻旁」→ 古籍「旧港」→ 华人再雅化为「巨港」（[7]）。
- **新加坡** Singapura（梵语「狮城」）：华人拆音造「新＋加＋坡」，另造「星洲」「石叻（Selat 海峡）」（[12]）。
- **仰光** Yangon：音译「漾贡」→ 雅化为「仰光」（仰＋光，吉祥字）（[14]）。
- **暹京 / 泰京**：华人对曼谷的「京城」雅称，用「京」作首都通名（[6]）。
- **山口洋** Singkawang：纯华人自造的「山＋口＋洋」，客家话 Sân-khiéu-yòng，完全脱离原音（[15]）。

**提炼出的黄金规律**：华人给南洋城市命名的**三阶段演化路径**——
> 直接音译（拗口多音节）→ 谐音压缩（2–3 字）→ 附会吉祥/地理/信仰字（雅化）。
凡「既像音译又含义吉祥」的双关名（泗水、仰光、巨港、西贡），是最地道的「海洋中国」风格。

### 1.3 郑和下西洋 + 明清「公司」地名遗存

- **三宝** 专名簇（源自郑和「三宝/三保太监」）：三宝垄 Semarang（简称「垄川」）、三宝颜 Zamboanga（词源存疑，一说郑和驻扎，一说马来语「鲜花之城」）、三宝山/三保山、三宝井（[2][13]）。
- **兰芳公司**（西婆罗洲，1777–1884，罗芳伯，客家人）遗存地名：首都**东万律**（Mandor 音译）、坤甸 Pontianak、山口洋 Singkawang、三发 Sambas、喃吧哇 Mampawa、戴燕/大院 Tayan、双沟月 Sekadau、万劳 Molor、劳劳 Lara（[3]）。
- **「公司」体制**：kongsi 本为中文「公司」，被马来/荷语借用后专指华人会党/矿场自治组织，再回流华语。首领称「大唐总长 / 大唐客长」——「大唐」作为华人海外政权的自称国号是极佳的虚构素材。
- **「埠头」聚落通名**：坤甸、山口洋都分「老埠头」（东，潮州帮）与「新埠头」（西，客家帮），「埠头」＝码头聚落，是南洋华人市镇最典型的通名（[11][15]）。

## 2. 东南亚语言汉字对音层（据此倒推自然中文名）

### 2.1 汉越音（Sino-Vietnamese）高频吉祥字对音表

汉越音高度规整，可直接当「中→越→中」双向字典用。反向使用（挑汉字→读汉越音→得到越南式地名）是最自然的生成法：

| 汉字 | 汉越音 | 汉字 | 汉越音 | 汉字 | 汉越音 |
|---|---|---|---|---|---|
| 河 | Hà | 海 | Hải | 江 | Giang |
| 山 | Sơn | 湖 | Hồ | 洲/珠 | Châu |
| 安 | An | 平 | Bình | 泰 | Thái |
| 顺 | Thuận | 和 | Hòa/Hoà | 永 | Vĩnh |
| 福 | Phúc | 禄 | Lộc | 寿 | Thọ |
| 新 | Tân | 兴 | Hưng | 隆/龙 | Long |
| 明 | Minh | 光 | Quang | 华 | Hoa |
| 富 | Phú | 贵 | Quý | 金 | Kim |
| 玉 | Ngọc | 宝 | Bảo | 广 | Quảng |
| 东 | Đông | 南 | Nam | 西 | Tây |
| 城 | Thành | 港 | Cảng | 口 | Khẩu |
| 镇 | Trấn | 会 | Hội | 定 | Định |
| 义 | Nghĩa | 仁 | Nhân | 德 | Đức |

**要点**：
- 汉字「龙」与「隆」在汉越音**同为 Long**，越南地名的 Long 兼具「龙/隆」双义——生成时可用「隆」表兴旺、「龙」表祥瑞，二者可互换。
- 汉越音保留中古音（如「金」kim、「心」tâm 保留 -m 尾；「国」quốc、「福」phúc 保留入声 -c 尾），故越南式中文名天然带**闭口尾（-m）与入声尾（-p/-t/-k 转 -c）**，这是「一眼越南味」的音韵特征。

### 2.2 马来语/印尼语对音（闽南、潮州、客家帮口音）

闽粤客方言是华人音译东南亚地名的主力，对音规律：

- **Bang**（马来/泰语「河畔聚落」）→「曼/班/邦」：曼谷。
- **Kuala** →「吉隆」：吉隆坡 Kuala Lumpur（Lumpur＝泥，「坡」）。
- **Tanjung**（海角）→「丹绒」。
- **Pulau**（岛）→「布路/浮罗」：槟榔屿《海录》作「布路槟榔」。
- **-pur/-pura**（城）→「坡」：Singapura → 新加坡。
- **Selat**（海峡）→ 闽南「石叻」（sek-lat）。
- **pasar**（市场）→「巴刹」。
- **kongsi**（公司）→「公司」（中文借出又回流）。
- **Pontianak**（马来传说难产女鬼）→「坤甸」。

**规律**：马来/印尼语多开音节、-ang/-an/-ong 尾，华人用**闽南/潮州/客家入声与鼻化韵**去对，产出「叻、坡、曼、丹、甲、甸、汶」等短促音节；再用一个雅化汉字收尾（港/坡/埠/城）即可「汉化」。

### 2.3 泰语 / 缅语 / 高棉语对音（简）

- 泰语：Bang →「曼」；Nakhon（城）→「洛坤/六坤」；Krung（京城）→「恭贴」；华人**按潮州话**对音。
- 缅语：Yangon →「漾贡」→「仰光」（雅化）；Bago/Pegu →「勃固」；Mergui →「丹老」。
- 高棉语：Piem（港口/出海口）→ 河仙故地「边」；Sài Gòn →「柴棍」→「西贡」。

## 5. 音韵与结构约束

- **字数**：汉越/华人自造名 **2–3 字**为主（河内、会安、泗水、巨港、槟城）；音译名 **2–4 字**（曼谷、巴邻旁、苏腊巴亚）。
- **音节尾**：
  - 闭口尾 **-m**（金 kim、心 tâm、深 thâm）、鼻音尾 **-n/-ng**（安 an、隆 long、清 thanh）。
  - 入声尾 **-p/-t/-k**（粤闽客：叻 -k、甲 -p、福 -k；汉越音转 -c）。
  - 开音节（河 Hà、巴 ba）。
- **「海洋中国」vs 中原命名的可辨识差异**（如何一眼看出是南洋风格）：
  1. 通名用海贸词（港/埠/洲/屿/浦/澳/坡/叻/巴刹），而非中原的「城/镇/州/县/堡/驿」。
  2. 专名密集出现热带物产字（椰/槟/榴莲/胡椒/沉香/苏木/锡/燕窝）。
  3. 出现借词汉写音节（叻/曼/丹/坡/巴刹/布路/洛坤）。
  4. 出现闽粤客方言字（厝/寮/坑/墟/围/涌/埗/岙）。
  5. 双关雅化名（泗水/仰光/巨港/西贡——音近洋名、义近吉祥/地理）。
  6. 三宝/大唐/妈祖/大伯公/公司等华人特有词做专名。

```
信仰     = [妈祖, 天后, 观音, 关帝, 大伯公, 清水, 三宝, 天妃, 王爷, 水仙, 福德]
```

**通名表**（见第 3 节），分两级：
```
正式通名 = [港, 埠, 洲, 屿, 浦, 津, 渡, 澳, 湾, 城, 镇]
口语/借词 = [坡, 叻, 巴刹, 公司, 丹绒, 埠头]
行政通名(越南式) = [城庯, 市社, 县, 社, 坊, 省]
```

### 6.2 组合规则（三大生成器）

**A. 汉越吉祥式（越南/占城/柬埔寨沿海）**
`专名 = 吉祥字/主题字 + 吉祥字/地理字`，2 字，可加行政通名。
例：新安、隆平、海福、金瓯、顺海、广南、明洲、嘉定、会安、河仙、芹苴（音译位）。
```
随机示例：安平 / 泰和 / 永福 / 顺海 / 光化 / 富寿 / 隆兴 / 新会
带通名：安平埠 / 顺海口 / 隆兴城庯 / 富寿坊
```

**B. 海贸物产式（马来半岛/爪哇/苏门答腊/婆罗洲/菲律宾）**
`专名 = 热带物产/海产/海贸字 + 通名`，2–3 字。
例：槟榔屿、胡椒港、锡港、椰港、珠澳、珊瑚礁、燕窝岛、船澳、帆津。
```
随机示例：槟港 / 椰埠 / 椒屿 / 珠浦 / 沉香澳 / 锡津 / 燕窝屿 / 豆蔻港
```

**C. 音译雅化式（最难、最「地道」的机制）**
步骤：
1. 取一个马来/泰/缅/高棉语多音节词的**音首音节**（可自造假词）。
2. 用闽/粤/客方言读音挑 2 个汉字作**谐音**（拗口无义）。
3. 把其中 1–2 字替换为**近音吉祥/地理字**，构成「既音近、又雅」的双关。
```
伪词示例：Sambawa → 三巴哇(谐音) → 三宝洼 / 山宝华
           Kelanpur → 吉兰坡(谐音) → 吉隆坡 / 麒麟坡
           Marantang → 马兰塘(谐音) → 马兰港 / 妈兰塘
```

### 6.3 音译模拟器（伪造「像东南亚地名的中文」）

构造假马来语词，再用规则映射回汉字：

- 音节模板：`[C][V] + [C][V] + ...`，多开音节（-ang/-an/-ong/-ung）。
- 对音映射（闽/潮/客）：
  - /ka/→吉/加/甲，/ku/→古/谷，/ki/→基/己
  - /la/→拉/罗/喇，/li/→里/利，/lu/→鲁/六
  - /ma/→马/麻/妈，/mi/→米/美，/mu/→武/木
  - /ta/→打/达/丹，/tan/→丹/单，/tang/→堂/丹绒
  - /na/→那/拿，/nang/→南/难
  - /sa/→沙/三/苏，/si/→西/泗，/su/→苏/素
  - /pa/→巴/巴刹，/pu/→布/浮罗，/pur/→坡
  - /nga/→雅/衙，/ban/→班/曼/万，/bang/→曼/邦
- 收尾：加一个雅化通名/吉祥字完成「汉化」。

### 6.4 禁忌过滤（生成后必须过筛）

1. **避真实地名**（见第 7 节黑名单 + 白名单比）。
2. **避不雅/凶字**：死、亡、崩、沉、陷、绝、败、瘟、疫、鬼、尸、灾、祸。
3. **避现代专名雷同**：不得撞中国省级/地级/县级行政区名、知名城市名（如「安平」可，「北平/上海/广州」不可）。
4. **音近去歧义**：结果若与敏感词、粗口、政治人物名同音，替换。
5. **帮口一致**：同一城不得混用跨帮方言字（闽南「厝」与广府「墟」不要拼在同一聚落名里）。
6. **通名单一**：一个名字只保留一个通名（「槟榔屿港」冗余，取「槟榔屿」或「槟港」）。
7. **去重**：生成池内 + 与历史真实池比对去重。

**泰国**：曼谷、清迈、合艾、普吉、宋卡、北大年、洛坤、董里、呵叻、大城（阿瑜陀耶）、吞武里。
**马来半岛**：马六甲/满剌加、槟城/槟榔屿、吉隆坡、柔佛、霹雳、雪兰莪、森美兰、彭亨、吉兰丹、丁加奴、新加坡/星洲/石叻、新山。
**印尼**：坤甸、山口洋、三宝垄、巨港/旧港/巴邻旁、泗水/苏腊巴亚、棉兰、雅加达、万隆、望加锡、巴东、巴厘、占碑、马辰、三马林达。
**菲律宾**：马尼拉、吕宋、宿务、苏禄、三宝颜、达沃、怡朗、碧瑶。
**缅甸**：仰光/漾贡、勃固、丹老、毛淡棉、土瓦、曼德勒、八莫、腊戍。
**柬埔寨**：金边、暹粒、马德望、磅湛、西哈努克。

**自检动作**：
1. 生成后全量字符串比对上述黑名单（含 2 字核心，如「仰光/泗水/巨港」精确比对）。
2. 比对前 2 字的**同音字变体**（如「泗水」→「四水/思水」也建议避，因读音近似真实名）。
3. 若刻意致敬某真实名，可保留其**构词骨架**（如「槟榔→椰、槟、榴」的物产+屿模式）而非照搬字面。

## 附：一页速查（工程落地用）

- **最快生成公式**：`[吉祥字/物产/海贸字] + [正式通名]`（2–3 字），或 `[谐音双字] + [雅化通名]`。
- **最「地道」机制**：音译 → 谐音 → 雅化（泗水/仰光/巨港/西贡四例为模板）。
- **三宝/大唐/妈祖/大伯公/公司** 是最鲜明的「海洋中国」专名标签。
- **帮口字**（厝/寮/坑/墟/围/涌/埠头）决定聚落的地方口音气质。
- **避让**：生成后必过第 7 节黑名单 + 同音变体 + 帮口一致性 + 通名唯一性。
