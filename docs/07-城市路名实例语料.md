# 中国城市路名实例语料与统计规律调研报告

> 用途：为 Transport Fever 3「中国街道名」MOD 提供真实路名的实例语料、命名规则与生成器校准依据。
> 调研方法：web_search 找线索 + pwsh 走本地代理抓正文；`web_fetch` 全程不可用（DNS 劫持），百度百科 403，改用维基百科、央广网、地理学报、地方新闻等可通源。
> 数据口径说明：凡能追溯到具体来源的统计均标注来源与年份；无法核实的统一标注「存疑」或「估算」。

---

## 0. 核心结论速览（先给生成器看的）

- **通名三巨头**：路（≈50%+）＞ 街（≈20%）＞ 大道（主干道专用）——巷/弄/胡同按城市地域替换。
- **专名四大来源**：政治建设类、地名移植类、山水吉祥类、科教发展类，四者约占 85%+。
- **全国级高频**：中山路 653 条（2021），人民路 + 建设路并列全国市区重名第一（各 129 条）。
- **字数主流**：3 字路名（专名 2 字 + 通名 1 字）是绝对主流，4 字靠「方位词」或「大道」撑起。
- **地名移植硬规则**：省名 = 南北向、城市名 = 东西向、按原籍方位落位（上海范式）。

> ⚠️ **最重要的一条提醒**：真实中国路名**极少用音译洋名或企业名**（《地名管理条例》明确禁止），MOD 里若出现大量「Apple 路 / 特斯拉大道」会瞬间出戏。要「像中国」，就守「专名 + 通名」二字结构。

## 1. 按城市取样分析（12 城，南北东西梯度）

> 示例路名均为真实存在的路名，可作为风格参照。带 ★ 的是该城"招牌级"路名（辨识度最高）。

### 1.1 北京 ——「胡同·条·大街」的皇城网格
- **主导通名**：胡同（内城老城）、条（东四/西四片区数序）、街/大街（骨架干道）、路（环路与新城）。
- **典型专名主题**：城门（前门/崇文门/宣武门/朝阳门/阜成门/德胜门/安定门/东直门/西直门/广安门/永定门…）、衙署府第（王府井、太仆寺街、按院胡同、东厂/西厂）、寺庙（隆福寺、护国寺、白塔寺、法源寺、广济寺）、集市（米市大街、灯市口、花市、珠市口、羊市口）、水系（什刹海、积水潭、后海、三里河、银锭桥、亮马河）。
- **命名体系特征**：① 网格序列——「条」数序化（东四头条~东四十四条、西四北头条~西四北八条、东四十条）；② 以城门为锚点的环路/放射线体系；③ 老城以历史地名为骨架，新城（中关村/上地/学院路）转向科教与功能名。
- **示例路名（25 个）**：南锣鼓巷★、帽儿胡同、雨儿胡同、菊儿胡同、蓑衣胡同、百花深处胡同、东四十条、东四十四条、西四北头条、府学胡同、国子监街、烟袋斜街★、琉璃厂东街、杨梅竹斜街、大栅栏★、鲜鱼口、牛街、灯市口大街、米市大街、鼓楼东大街、南池子大街、东华门大街、长安街★、前门大街★、王府井大街、金融大街、中关村大街、学院路、知春路、上地十街。

### 1.2 上海 ——「路」的绝对主导 + 地名移植标本
- **主导通名**：路（压倒性多数）、街（老城厢少量，如方浜中路一带）、弄/支路/坊/里/邨（石库门里弄）、大道（浦东大道、世纪大道，少而精）。
- **典型专名主题**：地名移植（省名+城市名，见第 3 节专题）、历史/租界遗留（南京路、延安东路=原爱多亚路、淮海中路=原霞飞路、武康路=原福开森路）、老城厢水系（方浜、肇嘉浜、陆家浜、南市）。
- **命名体系特征**：全中国最规整的「地名移植 + 方位落位」体系；道路几乎清一色用「路」；里弄以「弄/坊/里/邨」作生活性支路通名。
- **示例路名（28 个）**：南京东路★、南京西路★、淮海中路★、西藏中路、西藏南路、四川北路、四川中路、河南中路、山东中路、山西南路、江西中路、福建中路、浙江中路、广东路（例外，东西向）、汉口路、九江路、福州路、延安东路、金陵东路、北京东路、天津路、宁波路、乌鲁木齐中路、衡山路、武康路★、思南路、甜爱路、多伦路、愚园路、长乐路、番禺路、田子坊★、步高里、建业里。

### 1.3 广州 ——「路/街/巷 + 西关『甫/约/通津』」
- **主导通名**：路、大道（广州大道、黄埔大道、芳村大道）、街/巷（骑楼老街）、约（西关「约」）、甫（第十甫、十一甫、上九/下九）、通津（通往码头的路）。
- **典型专名主题**：历史商埠（西关、十三行、沙面、状元坊）、宗教（光塔、怀圣寺、六榕、光孝寺、海幢寺）、功能集市（米市、纸行、卖麻街、象牙街、榨粉街、白糖巷）、河涌。
- **命名体系特征**：粤式通名高度地域化（甫/约/通津/巷）；数字串联地名（一德路、二沙头、三元里…十甫路）；文革期间大量更名（恩宁路、永汉路→北京路等）。
- **示例路名（26 个）**：北京路★、上下九路★、第十甫路、恩宁路★、龙津西路、长寿路、宝华路、逢源路、多宝路、一德路、二沙岛、三元里、六榕路、德政中路、文明路、中山六路、中山大道、广州大道、黄埔大道、东风东路、环市东路、天河路、体育西路、寺贝通津、云海通津、状元坊、十三行路、沙面大街、解放中路、起义路、人民南路、芳村大道。

### 1.4 深圳 ——「大道」为王的新城标本
- **主导通名**：大道（深南大道、滨海大道、北环大道）、路（福华路、红荔路、笋岗路）、街（华强北步行街、东门老街）。
- **典型专名主题**：现代抽象吉祥字（深南/福田/福华/福强/红岭/红荔/彩田/梅林/香蜜湖/后海/华侨城）、工程口岸（罗湖、文锦渡、皇岗）、商业（华强北、东门、海岸城）。

### 1.5 成都 ——「街/巷/坝」的官署府第老城
- **主导通名**：街/巷（老城为主）、路（人民南路、红星路、蜀都大道、天府大道）、巷子（宽窄巷子）、坝（华西坝）。
- **典型专名主题**：历史官署府第（总府、提督、督院、正府、公馆）、忠义纪念（忠烈祠、双忠祠、岳府街）、水系（府河、南河、锦江、浣花、武侯祠）、休闲文化（春熙、宽窄巷子、玉林）。
- **命名体系特征**：官署/府第地名密集（全国少见）；「巷子」是成都口语通名；人民南路（天府中轴）是「人民」系列最著名的一条。

## 3. 地名移植命名法专题（重要）

### 3.1 上海范式（最规整，已核实）

**来源：央广网/上海发布 2017《上海以地名命名的道路 有哪些有趣的命名规则？》**

- **南北向干道 → 用省（区）名**：西藏路、云南路、贵州路、广西路、浙江路、湖北路、福建路、山西路、山东路、河南路、江西路、四川路……
- **东西向道路 → 用城市名**：北京路、宁波路、天津路、南京路、九江路、汉口路、福州路、延安路、金陵路……
- **方位落位规则（真实且系统）**：道路名所在位置与原籍在全国版图中的方位**大致对应**——
  - 东北地名（哈尔滨路、漠河路、呼兰路、牡丹江路…）集中在**杨浦、宝山**（上海东北角）；
  - 山东地名（崂山路、昌邑路、台儿庄路、枣庄路…）集中在**浦东**（华东方位）；
  - 西南地名（贵州路、广西路、云南路的支路：剑川路、鹤庆路、华坪路、丽江路…）集中在**长宁、徐汇、闵行**（上海西南角）。
- **例外（已核实）**：**广东路**以省名却是东西走向——因 1865 年改路名时，广州尚未设市、仍称「广东省城」，故按省名译作「广东路」（此例外来源见维基百科《广州地名》）。

**规则真实性结论**：这套「省=南北、市=东西、方位对应」规则**真实存在**，是公共租界工部局 1860 年代确立、延续至今的命名体系，但**并非无例外**（广东路最典型）。MOD 可用，但要保留少量"打破规则"的例外才更真实。

### 3.2 天津、青岛、南京的差异

- **天津（和平区原租界区）**：同样以全国省市地名命名（长春道、哈尔滨道、沈阳道、吉林路、辽宁路、山东路、河南路、山西路、重庆道、成都道、大理道、常德道、睦南道、马场道、郑州道……），**通名多用「道」**（五大道区域尤甚），方位大致对应（东北地名偏东北、西北地名偏西北），但**不如上海严格成体系**。1945–1946 年国民政府收回租界后统一用全国地名替换洋名。
- **青岛（老城区）**：以「长江南北各省名 + 山东省县市名」命名，**通名统一用「路」**，方位对应非常规整（已核实，见掌上青岛 2017）：
  - 西镇（西南部）：云南路、贵州路、四川路（东西向三大干道）+ 西藏路、西康路 = 西南五省齐；
  - 大港、小鲍岛（偏北偏西）：新疆路、甘肃路、青海路、绥远路→包头路、热河路、辽宁路、蒙古路、吉林路 = 西北/北方省名；
  - 中山路一带：南北向 山西路、河南路、河北路、山东路、浙江路、安徽路、江苏路（延长为上海路），东西向 广西路、湖南路、湖北路。
  - 另成系统：**八大关（关隘）、八大峡（峡谷）、八大湖（湖泊）、八大岭、八大岛、八大江/山、「海」字头**。
- **南京（民国首都规划）**：以「中山」系列为骨架（中山路、中山北路、中山南路、中山东路、中山门），配以「中央路、模范马路、汉中路、北京东路、广州路」等；**「中山」+方位**成为南京路名的精神中轴（民国子午线）。

### 3.3 可复用的「地名移植」生成规则（给 MOD 生成器）

1. **虚构省名/府名做南北向干道**：`{虚构省名}路`，南北走向，作为城市主轴级干道。
2. **虚构城市名做东西向道路**：`{虚构城市名}路`，东西走向，次级道路。
3. **方位对应策略**：把"被借用"地名按其在全国（或游戏世界观地图）的方位，映射到本城对应方位片区：
   - 东北地名 → 本城东北片区；西北地名 → 本城西北片区；西南地名 → 本城西南片区（可连用 3–5 个同片区地名，形成"地名扎堆"）。
4. **保留例外**：约 5–8% 的道路故意"违和"（如某省名做成东西向），提升真实感。
5. **扩展维度**（参考青岛，供生成器做"地名系列"）：除省市名外，还可成系列地用——
   - 关隘（山海关/嘉峪关/居庸关/函谷关/紫荆关/宁武关…）、
   - 峡谷（巫峡/西陵峡/瞿塘峡/三门峡/刘家峡…）、
   - 湖泊（太湖/西湖/洞庭湖/鄱阳湖/巢湖/洪泽湖…）、
   - 山川（燕山/太行山/井冈山/武夷山/庐山/峨眉山… × 长江/黄河/珠江/嘉陵江…），
   每一系列内**东西向用一类、南北向用一类**（如青岛"东西向=江、南北向=山"）。

## 4. 时代分层特征

### 4.1 明清老城（—1911）
- **通名**：街、巷、坊、里、胡同、弄、条、牌楼、门、市、口、桥。
- **专名高频词**：城门（XX门）、衙署（总府/提督/督院/太仆寺/按院）、寺庙（XX寺/庙/宫/庵/观）、集市（米市/菜市/灯市/花市/骡马市）、宗族姓氏（X家巷/X家湾/X家庄）、地貌（坡/坎/井/桥/沟）、牌坊。
- **风格**：功能性 + 就地取材，无系统规划，最"有烟火气"。

### 4.2 民国商埠与租界（1911–1949）
- **通名**：路、马路、大马路、道（天津）。
- **专名高频词**：中山、民族、民生、民权、三民、模范、大马路/二马路（数序）、省市地名（移植）、租界洋名（后改，如霞飞路→淮海中路）。
- **风格**：纪念性（中山路遍地）、地名移植体系成型、租界洋名遗存。

### 4.3 1949–1978 计划经济期
- **通名**：路（普及为全国主流）、街、大道。
- **专名高频词**：解放、人民、建设、新华、红旗、红星、朝阳、东风、胜利、和平、团结、光明、幸福、青年、劳动、工农、跃进、大庆、爱国、五一/七一/八一、长征、抗美、友好。
- **风格**：全国高度雷同的政治建设词汇（人民路/解放路/建设路/新华路等全国级路名多在此期普及）。

### 4.4 1978 后开发区
- **通名**：大道、路。
- **专名高频词**：科技、创业、发展、振兴、开发、高新、创新、科学、工业、世纪、新世纪、改革、开放。
- **风格**：经济话语 + 地名移植重启（新区重新借用省市地名）。

### 4.5 2000 后新区
- **通名**：大道、路。
- **专名高频词**：世纪、未来、科技、信息、数码、软件、生态、景观、滨江、滨湖、临港、空港、智慧、云、创、芯、谷、湾；以及「行政区划 + 方位 + 数序」网格（凤城一路~十路、天府一街~五街、星海街）。
- **风格**：抽象化、国际化、生态宜居 + 数序网格。

### 6.5 硬性避坑（决定"像不像"的底线）
1. **禁洋名/企业名**：《地名管理条例》2022 明确「不以外国人名、地名作地名；不以企业名称或商标名称作地名」。MOD 出现「Apple路/特斯拉大道」会立刻穿帮。
2. **专名+通名缺一不可**：真实路名几乎都是「专名 + 路/街/巷/大道」，不要生成「长安」「紫金」这种无通名的裸名。
3. **通名与尺度匹配**：大道=主干道，巷/弄/胡同=窄路，路/街=通用。
4. **地域绑定**：胡同→北京、弄→上海江南、坡坝坪→重庆、甫/约/通津→广州、道→天津租界。
5. **保留少量例外**：5–8% 的地名移植"违和"（如省名做东西向），少量"趣味名"（冰淇淋胡同、猛追湾）点缀，避免千篇一律的 AI 味。
