# 中国街道命名规则规格书

> 用途：供 `Transport Fever 3`「中国街道名」MOD 的代码生成器使用。本文整合自 4 份本地调研报告（`research/05` 通名与专名体系、`06` 命名规范与法规、`07` 城市路名实例语料、`08` 地域分型），**不新增未经原报告支持的事实**；原文标注「存疑」「待核实」「估算」处一律原样保留。
>
> 阅读约定：
> - **通名**（generic）：街名尾巴，标识道路等级/形态/地域（路、街、巷、弄、胡同、涌、厝…）。
> - **专名**（specific）：街名头，提供语义主题（人民、中山、桂花、徐家…）。
> - 一条街名 = **专名 + 通名**；生成器的核心动作是「专名部件池 × 通名表 × 地域风格」的加权组合 + 合法性/谐音/避让过滤。
> - 标 **〔存疑〕** / **〔待核实〕** / **〔估算〕** 者沿用原报告口径，可编程实现时应保留该标记、勿当作硬事实。

## 1. 总则与合规基线

### 1.1 法定结构（专名 + 通名）

- 《地名管理条例》（国务院令第 753 号，2022-05-01 施行）第九条：「地名由**专名**和**通名**两部分组成。」（来源：06 号 §1.1，中国政府网原文）
- 《地名管理条例实施办法》（民政部，2024-05-01 施行）第二十五条官方定义：
  - **专名** = 地名中为**个体地理实体所专有**的语词部分（如「长安街」的「长安」）；
  - **通名** = 地名中为**同类地理实体所通用**的语词部分（如「长安街」的「街」）。（来源：06 号 §1.2）
- 结构式（来源：05 号 §0）：

```
[专名] + [通名]
 中山  +  路
 人民  +  大道
 史家  +  胡同
```

- **硬约束**：一个合法街名**必须且只能有一个通名槽位**，不得「路街」「巷弄」连用；不得单独以通名作地名/专名（来源：已废止《实施细则》第十四条「不单独使用通名词组作地名」，06 号 §2.1、§3.7 A12/A13）。

### 1.4 字数与音韵约束

**字数分布（来源 05 号 §3.1；07 号 §2.3 实测估算〔估算〕）**：

| 字数 | 构成 | 占比（07 号，估算） | 例 |
|---|---|---|---|
| 3 字 | 专名 2 字 + 通名 1 字 | 45–55% | 人民路、中山路、建设路、汉正街 |
| 4 字 | 专名 2 字+方位 / 专名 3 字 / 专名 2 字+大道 | 30–35% | 中山北路、淮海中路、建设大道 |
| 5 字 | 专名 3 字+大道 / 专名 2 字+方位+大道 | 10–15% | 世纪大道、滨海大道、环市东路 |
| 2 字 | 专名 1 字 + 通名 1 字 | ≈5% | 大马路、横街、小巷 |
| 6 字+ | 多段叠加/历史长名 | 少量 | 亚美打利庇卢大马路（澳门） |

**构词规则（生成规则 R4，来源 05 号 §3.1/§3.2）**：
- 专名 1–3 字 + 通名 1–2 字，总长 **3–5 字为黄金区间**；专名越长、通名越短（3 字专名只配 1 字通名）。
- **不合法组合（生成器必须拦截）**：① 通名连用；② 专名 >3 字；③ 跨层错配（「马家大道」「桂花大街」「解放胡同」）；④ 构造通名当末端（「××高架」应作「××大道高架」后缀）；⑤ 方位词单独重复（「东东西西」「南南街」）。

**音韵禁忌（来源 05 号 §3.3）**：
- 不要求严格平仄，但**避免三连仄/三连平**、**避免同声母三连**（「江家街」jiāng jiā jiē）、**避免连续同音/近音字**（「洪鸿」「经京」）、**避免声调全平或全仄的四字名**（「华阳春晖」）。
- 通则：生成后做**拼音连读 + 声母/声调统计**，任一「三连同声母」或「四连同调」即弃或换部件。

### 1.5 谐音与不雅组合黑名单（来源 05 号 §3.4）

| 类别 | 判定 | 例证/处理 |
|---|---|---|
| 性/生殖谐音 | 字母序号「B 路」读如「逼」；专名末字+通名首字连读成粗口 | 跳过 B；改「甲/乙/丙」或「一/二/三」 |
| 死/丧/尸谐音 | 「四」谐「死」，但「四环路/四马路」是标准用法无害 | 保守地减少以「四」开头的低档路段；路名影响小 |
| 贬义/疾病谐音 | 癌、瘟、丧、穷 | 直接入黑名单 |
| 组合型笑点 | 专名+通名连读产生第二义 | 「高潮路」（真实但尴尬）「爱上路」「王八里」——需做整串拼音连读 + 分词歧义检查 |
| 方言谐音 | 粤语/闽南语「街(gāi)」「北」「沟」近不雅词 | 按目标城市方言预设额外黑名单 |

> 实现：维护「危险音节/词」表（逼/死/尸/癌/瘟/穷/高潮/爱上/王八…），对 `name` 的**整串拼音、逐字拼音、首字母缩写**三种形式做包含匹配（来源 05 号 §5.4）。

## 2. 通名体系

> 通名不是平铺词表，而是一条**从大到小、从「机动车大动脉」到「人行里弄」的等级链**（05 号 §1）。生成时通名必须与该路在游戏里的等级/长度/宽度匹配。
>
> **计数口径**（贯穿本文，供 §8 汇总复核）：通名分「通用层」与「地域专属层」两个登记簿，去重后计总数。

### 2.1 骨干层（大动脉）

| 通名 | 等级/规模 | 地域与历史色彩 | 生成示例 |
|---|---|---|---|
| 大道 | 快速路/主干，≥50m、≥4km | 现代感最强，新区/滨水/环城 | 人民大道、世纪大道、滨海大道、迎宾大道 |
| 大街 | 同上，商业繁华 | 传统商业主街，历史感强 | 中央大街、前门大街、正阳大街 |
| 路 | 最通用，次干/支路 | 全国通用、无色彩 | 中山路、解放路、建设路 |
| 街 | 与「路」同级，商业突出 | 略偏传统/商业，南方更常用 | 南京街、正阳街、天后街 |
| 道 | 与「路/街」同级 | 偏「老式/环状/滨河」，近代开埠城市多用 | 环城道、滨河道、海滨道 |
| 马路 | 口语化通俗通名 | 源自「马车行走之路」，正式命名少用，游戏可做低档/口语路段 | 老马路、洋马路 |
| 干线 / 快速路 | 功能性，非拼接通名 | 现代交通工程词汇，带方位/序号 | 东干线、快速环路 |
| 环路 / 环 / 外环 / 内环 | 环形主干 | 多配方位或序数 | 北环、东三环、外环路、内环路 |
| 高架 / 立交 / 桥 | 构造物，非独立路名 | 与道路名组合，不作末端通名 | XX高架路、XX立交桥、XX大桥 |

> 规则 R2：高架/立交/桥、环路、快速路这类「功能+构造」通名**不要直接做末端通名**，应作为后缀附加在已生成主路名上（「庆丰大道 → 庆丰大道高架 / 庆丰大桥」）。

### 2.3 片区层（小区/组团，非「路」）

> 这一层生成**住宅区/商业区/街区组团**名，与「路网」分开维护（规则 R3：片区层通名**不与骨干/次干层通名互换**）。

- **现代居住小区类**：园（香樟园、翠竹园）、苑（桂花园、沁芳苑）、城（四季城、滨江城）、府（XX 府）、邸、阁、轩、榭、庭、居（桃源居、怡然居）。
- **里弄/新村类**：里弄、新村（工人新村、阳光新村）、花园（桂花花园）、小区。
- **商业/办公类**：广场（时代广场）、中心（XX 国际中心）、大厦、写字楼群、商贸城。

> 计数：片区层通名计 **17 个**（园、苑、城、府、邸、阁、轩、榭、庭、居、里弄、新村、花园、小区、广场、中心、大厦）；「写字楼群、商贸城」为描述性举例，不单列通名。

### 6.2 生成流程（伪代码）

```
function generate(city):
    style = pick_style(city)              # 按城市规模/地域/历史选择风格（§5 + §4 地域标签）
    for i in 1..N:                        # N = 目标路名数量
        level = pick_level(road)          # 由该路在游戏里的等级/长度/宽度决定（§1.3 门槛映射）
        tp    = pick(T[level])            # 通名，按等级槽位
        cat   = pick_category(style, level)   # 专名类别，按风格/城市规模加权（§3.2、§4 themes）
        sp    = build_specific(cat, style)    # 拼出专名（1-3 字）
        name  = sp .. tp                  # 专名 + 通名
        name  = postfix(name, road)       # 可选附加：高架/大桥/环路/快速路（R2 后缀规则）
        if not valid(name): continue      # 过合法性 + 谐音 + 避让过滤（§6.3）
        dedupe(name)                      # 同城去重 + 同音去重（A10/A11）

-- build_specific 内部拼法（专名构造器，05 号 §5.3）
function build_specific(cat, style):
    1. 单部件：直接取池中词（"桂花"+"路"）
    2. 双部件连缀（主推，降撞名率）：a..b，如 吉祥+山水（瑞林）、方位+山水（东滨）、政治+政治（振兴和平）
    3. 姓氏式：surname.."家"（马家）→ 只配 lane 层
    4. 序号式：ordinal..("经/纬") 或 "第"..ordinal，仅 plaingrid 风格
    5. 地名移植式：从 cityname_pool 取，且 方位 ≈ 路段方位（上海范式，07 号 §3.1）
```

### 6.3 校验与过滤顺序（valid 函数）

> 顺序即管线：先做结构/禁止项（快判、成本低），再做音韵/谐音/避让（成本高）。合并 05 号 §5.4 与 06 号 §6。

```
valid(name):
    # —— 第一层：结构（B 表，必过，成本最低）——
    1. 地名 = 专名 + 通名 两段，否则 reject                       # B1
    2. 通名出现次数 != 1：reject（拦截"路街""巷弄"）              # A12/B2
    3. 专名字数 > 3 或总长 > 5（轨交站 ≤6）：reject              # B4 / R4
    4. 通名不得单独作专名：reject                                 # A13

    # —— 第二层：禁止项（A 表，命中即 fail）——
    5. 专名命中 违禁黑名单（外国人名地名/音译词/领导人/企业商标/封建迷信/不雅）：reject   # A1-A6
    6. 专名含 生僻字（超出常用 3500 字/《通用规范汉字表》一级即告警）：reject           # A7
    7. 含 外文字母/英文单词：reject                              # A8
    8. 含 纯数字序号（纪念数字地名仅白名单 五一/八一/一二九）：reject                    # A9

    # —— 第三层：等级匹配（C 表）——
    9. level==arterial 且 专名 in {姓氏式, 山水小词}：reject     # "马家大道""桂花大街"
   10. level==lane     且 专名 in {政治大词}：reject             # "解放胡同"
   11. 构造通名作末端（"××高架""××立交"）：reject，应改后缀     # R2

    # —— 第四层：音韵 + 谐音（§1.4/§1.5）——
   12. pinyin(name) 有 三连同声母 或 四连同调：reject
   13. pinyin(name) 命中 谐音黑名单（整串+逐字+首字母缩写）：reject
   14. 方言谐音黑名单（粤语/闽南语等，按城市方言预设）：reject

    # —— 第五层：重名/同音 + 避让（§7.2）——
   15. 同地图内 专名重名：reject                                # A10
   16. 同地图内 专名同音（拼音去声调）：reject                  # A11
   17. name 命中 著名路名黑名单：reject                         # §7.2
   18. name 命中 一线城市名+路 组合：视策略降级（见 §8 冲突 6）
    return true
```

> 实现要点（06 号 §6 E）：① 拼音同音校验——为每个已生成地名算普通话拼音（去声调），地图内两两比对；② 生僻字校验——内置《通用规范汉字表》或 GB2312 一级字集；③ 保留白名单历史纪念地名（中山、解放、人民、新华、八一、五一、长安、未央）作为「真实感」高优先级候选。

### 7.2 真实路名黑名单与无害撞名白名单

> 来源 05 号 §6（撞名两种性质）。

**A. 无害撞名白名单（高频通用，可放心用）**：人民路、中山路、解放路、建设路、和平路、新华路、文化路、公园路、迎宾路、朝阳路、青年路、团结路、光明路——全国成百上千条，游戏里出现**不会**让人意识到「抄了某条真路」，正是「像真」的来源。（中山路 653 条覆盖 91% 省级政区、人民路/建设路 129 条并列市区第一，来源 07 号 §2.1：高德 2021、地理学报 2024。）

**B. 著名独特路名黑名单（必须避让，一出现就指向具体城市）**：上海南京路、北京王府井、北京长安街、上海外滩、深圳深南大道、武汉汉正街、成都春熙路、广州北京路、厦门中山路步行街（05 号 §6；建议维护 100 条左右硬名单）。

**C. 一线城市名 + 路（降级/避让）**：南京路、北京路、上海路、广州路、深圳路、香港路——虽通用但易联想真实城市；游戏建议改用地级市/县级市/虚构城市名（05 号 §2.4、§6；详见 §8 冲突 6）。

**D. 自检清单（05 号 §6）**：
1. ❌ 撞「著名独特路名」黑名单？
2. ❌ 撞「一线城市名+路」？
3. ❌ 撞「地名移植」里的一线城市/省会组合（西藏路/四川路在上海是真实著名路）？
4. ❌ 不雅/歧义谐音（§1.5 三类检查）？
5. ✅ 高频通用名（人民/解放/中山/建设/和平+路）**无需避让**。
6. ❌ 与同城已生成路名重复？（去重集合）
7. ✅ 与「城市规模风格」匹配？（县城的「世纪大道」违和，一线城的「张家胡同」违和）

> 平衡点：游戏要的是「像真的」，而「像真」恰恰来自**高频通用名 + 大量不撞名的中频组合**；不要为「绝对不撞」把名字改成生僻冷怪。

### 7.3 反 AI 味策略

> 来源 07 号 §6.5 硬性避坑 + 05 号 §6 平衡点。

1. **禁洋名/企业名**：《地名管理条例》2022 明确「不以外国人名、地名作地名；不以企业名称或商标名称作地名」。MOD 出现「Apple 路/特斯拉大道」会立刻穿帮（07 号 §6.5-1）。
2. **专名+通名缺一不可**：不要生成「长安」「紫金」这种无通名的裸名（07 号 §6.5-2）。
3. **通名与尺度匹配**：大道=主干道、巷/弄/胡同=窄路、路/街=通用（07 号 §6.5-3）。
4. **地域绑定**：胡同→北京、弄→上海江南、坡坝坪→重庆、甫/约/通津→广州、道→天津租界（07 号 §6.5-4；08 号 §9.5 强标记不跨区）。
5. **保留少量例外/趣味**：5–8% 的地名移植「违和」（如省名做东西向），少量「趣味名」（冰淇淋胡同、猛追湾）点缀，避免千篇一律的 AI 味（07 号 §6.5-5）。
6. **派生组合降撞名**：双字政治词两两搭配（「团结大道」「振兴路」）、加修饰（「新解放路」「东建设路」）；序号/经纬改「经纬+山水」或「第 N+主题」（「第七滨河路」）降低重复率（05 号 §2.1/§2.2）。

## 8. 冲突与待裁定事项

> 逐条给「冲突内容｜来源｜建议仲裁方式」。仲裁建议为**生成器默认取值**，可由 MOD 作者以开关覆盖。

### 冲突 1：「浦 / 港 / 溇」水系通名的地域归属不一致

- **冲突内容**：05 号 §1.5 把「浜 / 泾 / **浦** / 塘 / **港** / 堰 / **溇**」整体划给「江南水乡」；而 08 号 §2.1 江南通名表**不含「港」「溇」**，08 号 §3.2 潮汕「海港地名多用**澳、浦、港**」、08 号 §6 闽台也有「澳」（海湾泊船港汊）。即「港」被 05 号归江南、被 08 号归潮汕海港；「溇」仅 05 号出现、08 号无印证。
- **来源**：05 号 §1.5 vs 08 号 §2.1 / §3.2 / §6.1。
- **仲裁方式**：① 「**浦**」保留江南（黄浦、杨树浦为吴语核心，08 号江南也列「浦」，双源一致）；② 「**港**」从江南默认通名池**降权或移除**，改归「沿海/潮汕·闽粤海港」二级标记（与「澳」同池）；③ 「**溇**」仅 05 号出现、缺第二源印证，标 **〔存疑〕** 并以低权重或禁用处理。

### 冲突 2：「大道 / 大街 / 路 / 巷」量化门槛各市不一

- **冲突内容**：「大道」门槛上海 ≥50m、成都 ≥60m、西安 ≥80m 且 ≥8000m（安丘 ≥50m 且 ≥4000m）；「路/街↔巷」分界西安 20m、成都 16m、安丘 <10m。国家层面无统一量化门槛，各市自定且差异显著。
- **来源**：05 号 §1.1（安丘 2024）vs 06 号 §2.2/§2.3（上海/西安市政发〔2019〕22 号/成都总规 2021—2035）。
- **仲裁方式（MOD 统一口径，取交集主流值）**：见 §1.3 推荐表——**大道 ≥60m 且 ≥4000m**（宽度取成都 60m、长度取安丘 4000m；西安式「≥80m 且 ≥8km」作「严格模式」开关）；**路/街 16–60m 且 ≥500m**（下限取成都 16m）；**巷/弄/里/胡同 <16m 且 ≤500m**（取成都最宽下限口径）。理由：取各市门槛的「交集」易实现且不名实不符；若地图明确设定为西安/上海，可启用对应城市的严格参数。

### 冲突 3：外文音译地名与「禁洋名」法规冲突

- **冲突内容**：《条例》9(五)「不以外国人名、地名作地名」、上海细则「不得使用外国地名」、西安「一般不以外文汉译词语命名」——但真实存在大量历史遗留音译路名：哈尔滨（果戈里大街、埃德蒙顿路，俄式）、港澳（皇后大道、弥敦道、轩尼诗道、亚美打利庇卢大马路，英葡音译）。MOD 若复现哈尔滨/港澳风味会撞法规。
- **来源**：06 号 §3.1 vs 07 号 §1.8、08 号 §3.2/§3.6。
- **仲裁方式**：**默认关闭外文音译池**（`foreign_name` 权重默认 0），符合现行法规；若 MOD 作者开启「哈尔滨/港澳」历史风貌，仅允许走**历史遗留白名单音译词**（果戈里、弥敦、轩尼诗等既有词），且**不得新造外国人名/地名音译**；在文档/注释中标注「历史遗留、依《条例》不新增」。港澳模式下 `foreign_name` 由 10 降为「白名单限定」。

### 冲突 4：「以人名作地名」与「纪念路名高频」的张力

- **冲突内容**：《条例》9(四)「一般不以人名作地名，不以国家领导人的名字作地名」——但「中山路」653 条（地理学报 2024）、哈尔滨「尚志大街/兆麟街/一曼街/靖宇街」、武汉「张之洞路/黄兴路/蔡锷路」等纪念性人名路名真实且高频。
- **来源**：06 号 §3.2 vs 07 号 §2.1/§1.8/§1.7、05 号 §2.8。
- **仲裁方式**：① 真实人名**仅走白名单**（中山、尚志、兆麟、一曼、靖宇、张之洞、黄兴、蔡锷、邹容、彭刘杨等历史约定俗成纪念地名），不新造真实人名；② 新造人名用**虚构姓名**（自创将领/先贤），符合《实施办法》第三条「字词与人名不存在特定联系的除外」的规范空间（05 号 §2.8）；③ 领导人姓名硬禁止（A2）。

### 冲突 5：纯数字序号路名与「禁纯数字序词」的边界

- **冲突内容**：西安导则「不得使用纯数字序词（城市环路除外）」——但武汉/上海「一马路～三马路」、郑州/石家庄「经一路/纬一路」、北京「头条～十四条」真实存在且是系统命名法。
- **来源**：06 号 §3.3 vs 07 号 §1.7/§1.1、05 号 §2.2/§3.5。
- **仲裁方式**：沿用 06 号区分口径——① **纪念性数字**（五一、八一、一二九）白名单保留；② **纯编号**（「3 号路」「18 号街」）**禁止**；③ 「经 N 路/纬 N 路」「一～N 马路」「头条～N 条」属**历史遗留系统性命名**，MOD 建议改用「第 N + 主题」（「第七滨河路」）或「方位 + 序号」替代纯编号，环路序号除外；「条」的数序（东四头条）仅限北京风格。

### 冲突 6：一线城市名 + 路 的「避让」与「地名移植风味」张力

- **冲突内容**：05 号 §2.4/§6 建议避让「南京/北京/上海/广州/深圳/香港 + 路」；但上海/青岛/台北风味恰恰依赖「北京路、南京路、四川路、西藏路」这类**真实一线地名移植**（07 号 §3.1 上海范式、§3.2 青岛、08 号 §2.2）。
- **来源**：05 号 §6 自检清单 vs 07 号 §3.1/§3.2、08 号 §2.2。
- **仲裁方式**：区分「游戏内自洽」与「现实撞名」——① 若游戏用**虚构城市名**做移植来源（`cityname_pool` 注入虚构省/市名），则既保留「地名移植」风味、又规避现实著名路名；② 若地图方位对应真实中国、必须用真实地名移植，则按 §7.2 判断：一线地名+路 属「著名/易联想」，走黑名单或降级为地级市/县级市名；③ 上海式「省名=南北、城市名=东西」的**结构规则**保留，仅把「城市名池」替换为虚构/低等级地名。

### 待裁定 1：胡同语源（存疑，不影响使用）

- **内容**：05 号与 08 号均采「胡同源自古汉语『巷/衖』、与南方『弄』同源、非蒙古语水井说」的主流结论，且均标 **〔存疑〕**（05 号「元大都 384 火巷 29 衖通数目存疑」；08 号「两类六说」）。两报告一致、无冲突，仅作**存疑保留**：MOD 文档保留「存疑」标注，生成不受影响。

### 待裁定 2：走向决定通名（南北街/东西路，存疑开关）

- **内容**：部分东北/北方城市有「南北走向称街、东西走向称路」约定（沈阳、长春），但非全国通则，南方与多数城市不区分。
- **来源**：05 号 §1.6（标 **存疑**）。
- **仲裁方式**：作为**可选的北方城市风格开关，默认关闭**。
