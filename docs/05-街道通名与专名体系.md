# 中国街道命名的通名与专名体系
### ——为《Transport Fever 3》虚构中国路名 MOD 的生成规则报告

> 用途：本报告面向工程落地，目标是让 Lua 生成器能机械产出**上千个"像真但不撞真实路名"**的街道名。全文以规则与部件表为主，例证用于锚定语感，不是抄名单。
> 数据来源：正文末「参考文献」列出实际抓取/检索到的 URL；无法确认处标注 **存疑**。

---

## 0. 一条路名的结构（先立骨架）

中国街道名的标准结构是：

```
[专名] + [通名]
 中山   +  路
 人民   +  大道
 史家   +  胡同
```

- **专名**（specific）：表达"哪条路"，来源见第 2 节，1–3 字为主。
- **通名**（generic）：表达"什么等级/什么形态的道路"，见第 1 节，1–2 字为主。

生成器的核心动作，就是从「专名部件池 × 通名表 × 地域风格」里做笛卡尔组合，再过合法性与谐音过滤（第 5 节）。所有规则都围绕这两个槽位展开。

---

## 1. 通名层级体系（最重要）

通名不是平铺的一堆词，而是一条**从大到小、从"机动车大动脉"到"人行里弄"的等级链**。生成时必须让通名与"该路在游戏里的等级/长度/宽度"匹配，否则会产出"XX 大道"却是一条 200 米死胡同的违和感。

### 1.1 权威等级对应（据地方民政部门道路命名标准）

据山东省安丘市民政局 2024 年发布的政策问答（原文抓取，见参考文献），通名与道路物理规模有一对一映射，这套口径在各地基本通用：

| 通名 | 红线宽度 | 长度 | 对应道路等级 | 语感/用法 |
|---|---|---|---|---|
| **大道 / 大街** | ≥ 50 米 | ≥ 4000 米 | 城市快速路、主干路 | 以通行为主称**大道**；两侧商业繁华称**大街** |
| **路 / 街** | 10–50 米 | ≥ 500 米 | 次干路、支路、乡村道路 | 一般用**路**；两侧商业功能突出称**街** |
| **巷** | < 10 米 | < 500 米 | 生活便道、居住区小路 | 居住区内部，非机动车尺度 |

> 推论（生成规则 R1）：**通名等级 ≈ 道路物理规模**。骨架层只能给主干路，次干层给支路/小路，片区层给"小区/组团"而非"路"本身。

### 1.2 骨干层通名（大动脉）

| 通名 | 等级/规模 | 地域与历史色彩 | 生成示例 |
|---|---|---|---|
| **大道** | 快速路/主干，≥50m、≥4km，通行为主 | 现代感最强，常用于新区、滨水、环城 | 人民大道、世纪大道、滨海大道、迎宾大道 |
| **大街** | 同上，但商业繁华 | 传统商业主街，历史感强 | 中央大街、前门大街、正阳大街 |
| **路** | 最通用，次干/支路 | 全国通用、无色彩，配任何专名都安全 | 中山路、解放路、建设路 |
| **街** | 与"路"同级，商业突出 | 略偏传统/商业，南方更常用 | 南京街、正阳街、天后街 |
| **道** | 与"路/街"同级 | 色彩偏"老式/环状/滨河"，近代开埠城市多用 | 环城道、滨河道、海滨道 |
| **马路** | 口语化通俗通名 | 源自"马车行走之路"（亦作 Macadam 路简称），正式命名少用，游戏可做低档/口语路段 | 老马路、洋马路 |
| **干线 / 快速路** | 功能性，非拼接通名 | 现代交通工程词汇，通常带方位/序号 | 东干线、快速环路 |
| **环路 / 环 / 外环 / 内环** | 环形主干 | 多配方位或序数 | 北环、东三环、外环路、内环路 |
| **高架 / 立交 / 桥** | 构造物，非独立路名 | 与道路名组合使用，不作通名单独成"路" | XX高架路、XX立交桥、XX大桥 |

> 生成规则 R2：**高架/立交/桥、环路、快速路这类"功能+构造"通名不要直接做末端通名**，它们应作为后缀附加在已生成的主路名上（如"庆丰大道 → 庆丰大道高架 / 庆丰大桥"）。

### 1.3 次干层通名（毛细血管）

| 通名 | 等级/形态 | 地域归属 | 历史/语源 | 生成示例 |
|---|---|---|---|---|
| **巷** | <10m、<500m，居住区 | 全国通用 | 古汉语，全国最通用的小路通名 | 马家巷、桂花巷、青云巷 |
| **弄** | 街坊内道路（分主弄/支弄） | **江南/上海** | 与"巷"同源（《南齐书》"南方曰弄"），上海里弄标准地址词 | 兴仁里弄、XX路 123 弄 |
| **里** | 街坊内道路/里坊 | **江南/上海/武汉** | 唐代"里坊"→北宋"街坊"，上海"兴仁里、平安里" | 平安里、兴仁里、仁厚里 |
| **坊** | 里坊/街坊 | 古城（西安、洛阳）、江南 | 里坊制遗存，历史感最浓 | 太平坊、永宁坊、崇仁坊 |
| **胡同** | 北方狭窄街巷 | **北京/华北** | 源自古汉语"巷"（学界主流：非蒙古语"水井"说），元大都规划定型，明清大量形成 | 史家胡同、砖塔胡同、棉花胡同 |
| **条** | 序列小巷 | **北京特有** | 北京"头条、二条、三条…"序列，常配方位（东四头条、西四三条） | 头条、二条、东四三条 |
| **径** | 小径 | 江南园林、现代小区 | 幽静、园林语感 | 曲径、竹径、松径 |
| **小街 / 横街 / 斜街** | 形态修饰 + 街 | 全国 | 方位/走向修饰语 | 大横街、斜街、水街 |

### 1.4 片区层通名（小区/组团，非"路"）

这一层生成的是**住宅区、商业区、街区组团**的名字，游戏里可用于"小区/园区/商圈"命名，与"路网"分开：

- **现代居住小区类**：园（香樟园、翠竹园）、苑（桂花园、沁芳苑）、城（四季城、滨江城）、府（XX 府，近年流行"XX府"）、邸、阁、轩、榭、庭、居（桃源居、怡然居）。
- **里弄/新村类**：里弄、新村（工人新村、阳光新村）、花园（桂花花园）、小区。
- **商业/办公类**：广场（时代广场）、中心（XX 国际中心）、大厦、写字楼群、商贸城。

> 生成规则 R3：片区层通名**不与骨干/次干层通名互换**。"XX 苑"是小区不是路，"XX 大道"是路不是小区。两条命名链分开维护。

### 1.5 南北地域差异（生成器必须能按"城市地理预设"切换通名池）

中国通名最显著的分布规律：**北干南湿、北陆南水**。北方通名偏"巷陌街坊"，江南水网通名大量借用"水系词"，岭南用"涌/滘/基围"，西南用"坝/坡/坎"。

| 地域 | 特征通名 | 例证 | 语源/成因 |
|---|---|---|---|
| **北方（华北/北京/东北）** | 胡同、条、巷、街、大院 | 史家胡同、东四头条、大杂院、XX大院 | 元大都坊巷肌理；东北"大院"为单位制住宅区 |
| **江南（江浙沪）** | 弄、里、坊、巷 + 浜/泾/浦/塘/港/堰/溇 | 兴仁里、枫泾、黄浦、洋泾浜、XX港 | 水网密布，通名借水文词；"里弄"是上海特色 |
| **岭南（粤桂闽）** | 街、巷、里、坊 + 涌(chōng)/滘(jiào)/基/围/埗(埠)/洲/沙 | 沥滘、琶洲、金沙洲、深水埗 | 珠三角水网，"涌/滘"为潮汐河道与分叉水道 |
| **西南（川渝云贵）** | 街、巷 + 坝/坡/坎/岩/坪/沱/垭 | 沙坪坝、杨家坪、牛角沱、青岩 | 山地地形通名（坝=平坝、坪=山间平地、沱=回水湾） |

**历史来源（按时间线）**：

1. **元大都胡同**：北京旧城以元大都为基础，棋盘式街巷，胡同定型于此（《析津志》载元大都"三百八十四火巷，二十九衖通"，数目**存疑**，但"胡同"一词元代已通行）。胡同语源主流观点是**源自古汉语"巷"，与南方"弄"同源**（蒙古语"水井/浩特"说已被语言学家批驳，见参考文献）。
2. **明清坊巷**：里坊制瓦解后转为开放街巷制，胡同数量在明清激增，成为北方小巷通名。
3. **租界"路"**：近代开埠城市（上海、天津、武汉、广州）在租界铺设新式马路，通行以"路/大道"对译西文 road/avenue，如上海南京路、天津原法租界霞飞路。**"路"作为通名的大规模普及与近代城市化同步**。
4. **近代"大道"**：民国及现代"大道"表宽阔新式马路，如中山大道、解放大道，是现代新区命名的默认骨干通名。

### 1.6 走向差异（存疑，但可作为地域风格开关）

部分东北/北方城市有"**南北走向称街、东西走向称路**"的约定（如沈阳、长春）。但这并非全国通则，南方与多数城市不作区分。**存疑**：建议生成器把"走向决定通名"作为可选的北方城市风格开关，默认关闭。

## 2. 专名来源分类（生成语料核心）

以下是专名部件池的分类学，每一类给例证 + 生成建议（哪些词能用、哪些词饱和、哪些要换新词）。

### 2.1 政治教化类
人民、解放、中山、建国、和平、新华、光明、团结、胜利、前进、友谊、民主、自由、红旗、八一、工农、革命、振兴、复兴、建设、发展、文明、和谐、富强。
> 规律：这是**全国最高频**的专名池，也是"人民路/中山路/解放路/建设路"之所以每个县城都有的原因。生成时可继续用，但为"像真不撞名"应**派生组合**：双字政治词两两搭配（"团结大道""振兴路"），或加修饰（"新解放路""东建设路"）。注意**"中山/解放/人民"直接+通名几乎必撞真实路名**（见第 6 节）。

### 2.2 方位序列类
- **方位**：东、西、南、北、中、上、下、前、后、内、外、左、右。常作前缀（东大街、西河沿、中山西路）。
- **序号**：第一、第二…（第一大道）；头条、二条…（北京）；一街、二街。
- **经纬网格**：经一路、经二路、纬一路、纬三路（郑州、石家庄等平原网格城市的经典命名法）。
- **数字化**：五一路、八一路、一二九街、三七街。
> 规律：序号/经纬路名几乎必撞真实路名（"经一路"全国泛滥），但**撞名无害**（见第 6 节）。生成时建议把数字与方位、主题词组合："经三路→"改"经纬+山水"或"第 N + 主题"（"第七滨河路"），降低重复率。

### 2.3 山水自然地物类（最高产、最安全的池）
山、岭、峰、岩、坡、岗、丘、崖；江、河、湖、海、溪、泉、潭、塘、湾、浦、洲、岛、沙、滩、港、滨；林、树、花、草、竹、松、柏、柳、梅、兰、菊、荷、桂、榕、槐、榆、桃、李、杏、枫、杉、梧桐、银杏。
> 规律：**"植物名 + 通名"是虚构路名最安全最高产的组合**（桂花路、香樟路、松柏路、榕树街），几乎不撞著名路名且语感真实。**"水文词 + 通名"**（滨江大道、临海路、望江路）次之。建议生成器把这一池作为默认主力。

### 2.4 城市与地名移植类（"地名移植"命名法）
南京路、北京路、天津街、汉口路、中山路、延安路、西藏路、四川路、广州路、苏州路。
> **这套"以他乡地名命名本城道路"的命名法在中国极普遍，规则明确**：
> 1. **典型城市**：上海（租界时期即以全国省、市、县命名马路，南京路/北京路/四川路/西藏路等，且**大致按中国地图方位布局**——杨浦多东北地名、普陀多西北地名、南部多华南地名）、郑州、天津、武汉等开埠/枢纽城市尤甚。
> 2. **方位对应规则**：移植地名在城内的布局**常与原地名在中国的方位对应**（东北地名放在城东北、西北地名在城西北）。生成器可为"枢纽/开埠型城市"开这个风格，并强制"移植地名方位 ≈ 路段方位"。
> 3. **避让**：移植地名 + 通用通名（"南京路""北京路""四川路"）在上海等城市是**真实著名路名**，生成时应避免"南京/北京/上海/广州/深圳/香港"等一线地名直接+路，或改用地级市/县级市（"宜宾路""九江路"仍可能撞，但撞名级别低、无害）。游戏可**虚构城市名**做移植来源（第 2.8 节同理）。

### 2.5 行业与功能类
车站、码头、机场、货场、工业、纺织、钢铁、化工、科技、金融、商业、食品、仓储、物流、医院、学校、文化、体育、图书馆、博物馆、公园、花园、港务。
> 规律：这类专名**按路段实际功能落位**（车站路、机场大道、工业大道、科技园路），且近代工业城市（沈阳、武汉、淄博）高频。生成时把"功能词"与"路段功能/城市产业结构"绑定：工业区出"纺织/钢铁/化工"，高新区出"科技/信息/软件"。

### 2.6 吉祥美好类
福、禄、寿、喜、财、安、康、宁、泰、昌、盛、兴、隆、和、顺、富、贵、荣、华、春、晖、阳、晨、旭、瑞、祥、吉、庆、丰、嘉。
> 规律：双字吉祥词（安康、安宁、昌盛、兴盛、祥和、吉庆、丰宁、瑞丰、华兴、泰和）是**传统城区与古镇**的主力专名池，语感温和、极安全。与"里/坊/巷/街"搭配最自然（泰和坊、祥和里、昌盛街）。

### 2.7 姓氏宗族类
X家巷、X家弄、X家胡同、X氏路、X家庄、X家坝。
> 规律：**"姓氏 + 家 + 通名"**是聚族而居的产物（马家巷、李家弄、张家胡同），是**低等级小路/里弄**的经典命名。生成规则：配"巷/弄/胡同/里"等次干层通名，**不配"大道/大街"**（"马家大道"违和）。姓氏池用百家姓常见单姓即可。

### 2.8 人名纪念类
中山、鲁迅、沫若、自忠、靖宇、继光、则徐。
> 规律：**现实中以人名命名道路需经审批、多为烈士/伟人**（自忠路、靖宇街、继光路）。游戏里**可用虚构人名**（自创将领/先贤/建城者），生成格式"单姓+名/号 + 路/大道"，语感立竿见影。注意：真实历史人名（鲁迅、中山、则徐）直接+通名极可能撞真路名，应改用虚构人名或改通名。

### 2.9 水文工程类
堤、坝、闸、桥、渡、码头、港口、运河、渠、埭、堰。
> 规律：工程通名多**附加在路名后**（XX 堤路、XX 桥路、XX 闸道），或作专名（坝上街、渡口街、运河路、渠东街）。水网城市（江南/岭南）高频，北方少用。

### 2.10 历史遗迹与新旧城
古城、老城、城墙、城门（东门/西门/南门/北门/大南门）、钟楼、鼓楼、牌坊、庙、寺、观、祠、会馆、文庙、城隍。
> 规律：**"地标 + 街/巷/里"**是古城命名法（东门街、鼓楼街、文庙巷、城隍庙街、牌坊街），语感古老。生成时给"古城/古镇"风格开这个池，配"街/巷/里/坊"。

## 3. 构词与音韵规则

### 3.1 总字数分布
- **3 字**（专名 1 字 + 通名 1 字）：中山路、北京街、桂花巷——最常见、最"标准"。
- **4 字**（专名 2 字 + 通名 1 字）：人民大道、解放大街、松柏胡同——次常见。
- **5 字**（专名 3 字 + 通名 1 字，或 2+2）：滨江大道、香樟路（3字）…实际 5 字多为"三字专名+二字通名"（世纪大道/创业大道）或"两字专名+双字通名"（XX 新村/XX 里弄）。
- **6 字以上**：少见，多为序列/方位扩展（东四头条、XX 高新技术产业园区路），应**避免**做普通路名。

**各部分长度搭配（生成规则 R4）**：专名 1–3 字 + 通名 1–2 字，总长 3–5 字为黄金区间；专名越长，通名越要短（3 字专名只配 1 字通名，"高新技术产业园区"这类长专名是地名而非路名）。

### 3.2 "专名 + 通名"拼接规则与不合法组合
**合法（高频）**：
- 双字实词/政治词/山水词/吉祥词 + 路/街/大道/巷（和平路、桂花巷、泰和坊）。
- 姓氏 + 家 + 次干通名（马家巷）。
- 方位/序号 + 主题词 + 通名（东滨江大道、第三建设路）。

**不合法/违和组合（生成器必须拦截）**：
1. **通名连用**：路路、街街、大道道、"XX 路街""XX 巷弄"——一个名字只允许一个通名槽位。
2. **专名过长**：4 字以上专名 + 通名，拗口且不真实。
3. **跨层错配**：姓氏/山水小词 + 大道/大街（"马家大道""桂花大街"），或政治大词 + 巷/胡同（"解放胡同"生硬）。
4. **构造通名当末端**：直接生成"XX 高架""XX 立交"（应作后缀附加）。
5. **方位词单独+通名重复**：东东西西、南南街。

### 3.3 声调平仄与拗口禁忌
- 不要求严格平仄（路名非韵文），但**避免三连仄/三连平**拗口，避免**同声母三连**（"江家街"jiāng jiā jiē 三连 j，"张家庄"尚可但"张庄镇"拗）。
- 避免**连续同音/近音字**（"洪鸿"、"经京"连用）。
- 避免**声调全平或全仄**的四字名（"华阳春晖"四平）。
- 通则：生成后做一次**拼音连读 + 声母/声调统计**，任一"三连同声母"或"四连同调"即弃或换部件。

### 3.4 不雅谐音禁忌（生成器必须内置黑名单）

**要避开的谐音类别**：
1. **性/生殖谐音**：数字化命名里的"A/B/C 路"中"B 路"读如"逼"（游戏若用字母序号，应跳过 B）；专名末字与通名首字连读成粗口。
2. **死/丧/尸谐音**："四"（sì）谐"死"，但"四环路/四马路"是标准用法、无害；民间的避讳主要在楼栋/楼层，路名影响小，游戏可**保守地减少以"四"开头的低档路段**。"十三/十四"楼栋避讳，路名基本无感。
3. **贬义/疾病谐音**：癌、瘟、丧、穷。
4. **组合型笑点**：专名+通名连读产生第二义（"高潮路"——真实存在但尴尬；"爱上路""王八里"等），生成后需做**整串拼音连读**与**分词歧义**检查。
5. **方言谐音（若目标方言区）**：粤语/闽南语里"街(gāi)""北""沟"等易与不雅词近音，生成器可按目标城市方言预设一个额外黑名单。

### 3.5 复数/序列路名的系统性命名
- **经纬网格**：经 N 路（南北）+ 纬 N 路（东西），郑州/石家庄经典。适合平原大网格城市。
- **数字序列**：一马路、二马路、三马路（武汉、上海有"一~X 马路"）；头条、二条（北京）；第一~第 N 大道。
- **方位分区**：同一主题词 + 东南西北中前缀（东滨江、西滨江、南滨江、北滨江），形成"片区主题词 + 四方格"系统。
- **字母分区**：A/B/C 区（现代新区），但注意"B 路"谐音，可用"甲/乙/丙"或"一/二/三"替代。

## 4. 城市规模与路名风格的关系

| 城市规模 | 主导专名池 | 主导通名 | 语感特征 | 生成示例 |
|---|---|---|---|---|
| **一线/新一线大都市** | 地名移植、政治教化、山水、现代功能（科技/金融/商务） | 大道、路、街、环路、高架 | 大气、国际化、多"大道/环路"，新区多科技创业词 | 世纪大道、滨江大道、科技园路、内环路 |
| **地级市** | 政治教化、山水、吉祥、功能 | 路、街、大道 | 稳健、功能分明 | 建设路、和平路、工业大道、文昌街 |
| **县城** | 政治教化（人民/解放/建设）+ 序号/方位 | 路、街、巷 | **"人民/解放/建设 + 序号/方位"是县城标配** | 人民路、建设一路、解放街、东门街 |
| **乡镇** | 姓氏、方位、地标、吉祥 | 街、巷、路、坝 | 聚族而居、地标命名 | 张家街、桥头街、文昌街、马家坝 |
| **村落** | 姓氏、自然地物、方位 | 庄、村、湾、坝、屯 | 多为村名而非路名，路多"村头/桥头/湾子" | 李家湾、杨家坝、桥头、东庄 |

> 新区（无论城市等级）普遍用"科技/创业/发展/创新/孵化/软件 + 大道/路"，古镇/老城用"历史遗迹 + 街/巷/里/坊"（第 2.10 节）。生成器应把"城市规模"作为**风格参数**，直接决定专名池权重。

### 5.3 组合规则（伪代码）

```
function generate(city):
    style = pick_style(city)            # 按城市规模/地域/历史选择风格
    for i in 1..N:                      # N = 目标路名数量
        level  = pick_level(road)       # 由该路在游戏里的等级/长度决定
        tp     = pick(T[level])         # 通名，按等级槽位
        cat    = pick_category(style, level)   # 专名类别，按风格加权
        sp     = build_specific(cat, style)    # 拼出专名（1-3字）
        name   = sp .. tp               # 专名 + 通名
        name   = postfix(name, road)    # 可选附加：高架/大桥/环路
        if not valid(name): continue    # 过合法性 + 谐音 + 避让过滤
        dedupe(name)
```

**build_specific 内部拼法（专名构造器）**：
1. 单部件：直接取池中词（"桂花"+"路"）。
2. 双部件连缀（主推，降撞名率）：`a .. b`，如"吉祥+山水"（瑞林）、"方位+山水"（东滨）、"政治+政治"（振兴和平）、"吉祥+吉祥"（昌盛）。
3. 姓氏式：`surname .. "家"`（马家）→ 只配 lane 层。
4. 序号式：`ordinal .. ("经/纬")` 或 `"第" .. ordinal`，仅 plaingrid 风格。
5. 地名移植式：从 `cityname_pool`（真实地级市名 ∪ 虚构城市名）取，且方位 ≈ 路段方位。

### 5.4 合法性与过滤（valid 函数）

```
valid(name):
    if 通名出现 != 1: reject                    # 拦截"路街""巷弄"
    if 专名字数 > 3 或总长 > 5: reject
    if level==arterial 且 专名 in {姓氏式, 山水小词}: reject   # "马家大道"
    if level==lane 且 专名 in {政治大词}: reject               # "解放胡同"
    if pinyin(name) 有 三连同声母 或 四连同调: reject
    if pinyin(name) 命中 谐音黑名单(整串+分词+首字母缩写): reject
    if name 命中 著名路名黑名单: reject         # 见第 6 节
    return true
```

**谐音黑名单构建**：维护一份"危险音节/词"表（含"逼/死/尸/癌/瘟/穷/高潮/爱上/王八"等），对 `name` 的**整串拼音、逐字拼音、首字母缩写**三种形式做包含匹配；若城市预设了方言区（粤语/闽南语），再叠加该方言的谐音表。

## 6. 真实路名避让策略

**撞名的两种性质**：
- **高频通用路名（撞名无害）**：人民路、中山路、解放路、建设路、和平路、新华路——全国成百上千条，游戏里出现**不会**让人意识到"抄了某条真路"。可放心用。
- **著名独特路名（必须避让）**：上海南京路、北京王府井、北京长安街、上海外滩、深圳深南大道、武汉汉正街、成都春熙路、广州北京路、厦门中山路步行街——这些是"城市名片"，一出现就指向具体城市，应进入**黑名单**。

**自检清单**：
1. ❌ 是否撞"著名独特路名"黑名单？（上述 + 各城市标志性路名，可维护一张 100 条左右的硬名单）
2. ❌ 是否撞"一线城市名 + 路"？（南京路、北京路、上海路、广州路、深圳路、香港路——虽通用但易联想到真实城市，游戏建议改用地级市/虚构城市名）
3. ❌ 是否撞"地名移植"里的一线城市/省会组合？（西藏路、四川路在上海是真实著名路）
4. ❌ 是否有不雅/歧义谐音？（第 3.4 节三类检查）
5. ✅ 高频通用名（人民/解放/中山/建设/和平 + 路）——**无需避让**，这正是"像真"的来源。
6. ❌ 是否与**同城已生成**的路名重复？（去重集合）
7. ✅ 是否与"城市规模风格"匹配？（县城的"世纪大道"违和，一线城的"张家胡同"违和）

> 平衡点：游戏要的是"像真的"，而"像真"恰恰来自**高频通用名 + 大量不撞名的中频组合**。不要为了"绝对不撞"把名字改成生僻冷怪，那样反而不像中国街道。
