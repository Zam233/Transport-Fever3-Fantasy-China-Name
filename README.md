# Fantasy Chinese Name — Transport Fever 3

为《Transport Fever 3》制作的**虚构中国名称集** MOD。名称集同时决定地图上的**城镇名、道路/车站名与居民姓名**。

> 全部地名为**虚构**，不复制任何真实中国城市或真实路名。

## 五套名称集

| 名称集 | 城镇命名 | 道路命名 |
|---|---|---|
| **中国·内地** | 汉地城镇命名 | 华北 + 江南 + 岭南 + 华中 |
| **中国·热带** | 汉人海商主导东南亚后的港埠命名 | 闽台 + 西南 |
| **中国·亚寒带** | 海参崴、庙街式的北疆命名 | 东北（华北） |
| **中国·沙漠** | 绿洲水利、屯垦军镇与民族语对音 | 内蒙古 + 西北 |
| **中国·综合** | 前四类加权混合 | 全部九大地域 |

## 安装
### 一键安装

前往游戏中的模组管理中下载本MOD

### 手动安装
把 `cn_names` 整个文件夹放进 TF3 的 MOD 目录：

```
…\Steam\userdata\<你的 Steam ID>\3493540\local\mods\cn_names
```

启动游戏 → MOD 列表启用 → **新建游戏时在设置里选择名称集**。

## 成就

本 MOD 在 `mod.json` 中标记为 `"cosmetic": true`。

按官方 MOD 手册，**仅外观类 MOD 可以设该标记为 true，从而不影响成就获取**；
手册同时列举了不能算作外观的情形：更快的载具、更大的容量、不同的产出等
——即任何影响模拟的改动。本 MOD 只改名字（城镇/道路/车站/居民），
不触碰任何模拟数值，因此属于外观类。

> 注意：若同时启用了别的影响模拟的 MOD，成就仍会被禁用。这是游戏的整体规则。
