# Transport Fever 3 — Fantasy China Name Set

为《Transport Fever 3》制作的**虚构中国名称集** MOD。名称集同时决定地图上的
**城镇名、道路/车站名与居民姓名**（TF3 的机制如此：游戏里只有一个「名称集」选项）。

> 全部地名为**虚构**，不复制任何真实中国城市或真实路名。

## 五套名称集

| 名称集 | 城镇命名 | 道路命名 |
|---|---|---|
| **中国·内地** | 汉地城镇命名 | 华北 + 江南 + 岭南 + 华中 |
| **中国·热带** | 汉人海商主导东南亚后的港埠命名 | 闽台 + 西南 |
| **中国·亚寒带** | 海参崴、庙街式的北疆命名 | 东北（华北） |
| **中国·沙漠** | 绿洲水利、屯垦军镇与民族语对音 | 内蒙古 + 西北 |
| **中国·综合** | 前四类加权混合 | 全部九大地域 |

## 安装

把 `cn_names` 整个文件夹放进 TF3 的 MOD 目录：

```
…\Steam\userdata\<你的 Steam ID>\3493540\local\mods\cn_names
```

启动游戏 → MOD 列表启用 → **新建游戏时在设置里选择名称集**。

## 命名规则要点

**结构铁律**：每条道路名都必须满足中国地名的法定结构 ——
**专名 + 通名**，且通名固定在末尾（如「人民路」「东四头条」「锦康艾里」）。
生成器强制执行：去掉通名后专名不得为空，因此不会出现纯通名（「路」「市社」）
或无通名的裸专名。

**内置的地名规范校验**（对应《地名管理条例》与各市命名细则）：

| 校验项 | 说明 |
|---|---|
| 外国人名地名 | 外文音译池默认整体关闭 |
| 生僻字 | 限 CJK 基本区，排除标注的生僻字 |
| 重名 / 重音 | 同一地图内不重名；谐音黑名单拦截 |
| 不雅 / 不吉谐音 | 词表拦截 |
| 通名自叠 | 拦「塘塘」式专名=通名、专名退化为通名 |
| 道路等级匹配 | 数据层含门槛表（大道 ≥60m 且 ≥4000m 等） |
| 真实著名路名 | 城市名片级路名进黑名单 |
| **道路名 vs 聚落名** | 道路后缀白名单，**不会**产出「石家庄」「邓屯」这类村名 |

**地域特色**由地域专属街巷用字承载（弄/浜/泾/埭/涌/滘/围/塱/埕/场/冲/垸/
塬/梁/峁/渠/泉/宗/卡…），但道路后缀始终是真正的路名用字。

**素材来源**：四类城镇命名规则与九类街道命名规则均由专门调研产出
（见 `docs/` 下的规格书），并逐条回溯到地名学与法规依据。

## 开发与自检

本 MOD 遵循 TF3 官方 MOD 手册的结构；仓库内附开发工具，可在**不启动游戏**的
情况下验证大部分行为。

```powershell
# 语法检查（只编译不执行）
texlua tools/syntax_check.lua cn_names

# Lua 5.1 兼容性（TF3 运行时疑为 Lua 5.1/LuaJIT，禁用 5.3 位运算符）
pwsh -File tools/lint51.ps1 -Path cn_names

# 按引擎方式加载并验证（load → 调 data() → 取函数表，含 6 类断言）
texlua tools/verify_engine.lua

# 道路名 / 聚落名判定（聚落后缀经 argv 传入，避免源文件含 CJK）
texlua tools/check_street_type.lua ...
```

`tools/verify_engine.lua` 会校验：入口导出 `data()`、5 个名称集可加载、
三大人名/城镇/道路函数返回类型正确、`num < 0` 返回全量、
**重复调用产出不同人名**（防止"所有人同名"回归）、道路名不含真实省市名、
道路名不以聚落通名结尾。

## 已知限制

- TF3 只有一个名称集选项，因此**无法**让城镇名与道路名分属不同风格。
- 亚寒带的道路风格取自「东北（华北）」地域池，因此其道路名会带华北色彩
  （胡同、条、屯 等作专名）。
- 道路名的「综合」风格由九大地域模板合并抽取，个别组合会比单地域风格生硬。
